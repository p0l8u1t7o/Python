# 成像條件管理與量測不變性驗證

| 項目 | 內容 |
|---|---|
| 文件編號 | SPEC-002 |
| 版本 | v1.0（第 1 階段） |
| 對應程式 | `xrayvision/core/quality.py`、`calibration.py`、`acquisition.py`、`units.py`、`validation.py` |
| 相關文件 | 產品規劃書 PLAN-001 第 3 節 |

本文件說明本平台如何處理 X 光拍攝條件（管電壓、功率、曝光）變動造成的成像差異，以及現場驗證的標準作業程序。

## 2. 成像品質閘門

### 2.1 判定方式

每張影像計算品質指標，依規則判定：

- **合格**：照常分析。
- **警告**：照常分析，結果註記「成像品質警告」。
- **不合格**：保留量測數據供檢閱，但不輸出判定，並提示重新拍攝。

規則來源依序為：平台預設 → 檢測模組預設 → 配方覆寫（依指標鍵覆寫）。

### 2.2 預設規則（初始值）

以下門檻依現有 Batch1、Batch2 影像訂定，取得現場參數掃描影像後需重新校正。

| 指標 | 說明 | 警告 | 不合格 | 適用影像 |
|---|---|---|---|---|
| `image.snr` | 背景訊雜比（中位強度 ÷ 雜訊） | < 80 | < 30 | 16-bit |
| `image.saturation_ratio` | 飽和像素比例 | > 0.1% | > 1% | 16-bit |
| `image.dark_ratio` | 過暗像素比例 | > 0.1% | > 1% | 16-bit |
| `bump_alignment.sites_used` | 可採用位點數 | < 30 | < 10 | 全部 |
| `bump_alignment.oblique_angle_deg` | 等效斜射角 | > 25° | > 30° | 全部 |
| `bump_alignment.measurable_ratio` | 可量測比例 | < 0.4 | < 0.2 | 16-bit |
| `bump_alignment.contrast` | 凸塊吸收對比 | < 0.04 | < 0.02 | 16-bit |
| `bump_alignment.edge_width_ratio` | 邊緣模糊寬度 ÷ 凸塊半徑 | > 0.2 | > 0.3 | 16-bit |
| `bump_alignment.pitch_deviation` | 實測間距與設計值偏差 | > 3% | > 8% | 全部（需像素尺寸與設計間距） |

現有影像的實測值：16-bit 影像訊雜比 190～270、無飽和、凸塊對比 0.117～0.135、邊緣模糊比例約 0.10，全部合格。

8-bit 轉存影像的灰階已被檢視軟體拉伸（約 25～35% 像素飽和），平台指標不適用；此類影像的結果一律僅供參考。

### 2.3 斜射影像偵測

設備可斜向觀察。斜射影像中，凸塊與焊墊有高度差造成的視差，無法用於對位量測。

- 方法：計算每顆凸塊輪廓的長短軸比與長軸方向，將扁平度沿長軸方向做向量平均，得到「一致扁平度」，再換算為等效斜射角。凸塊本身不圓的方向是隨機的，平均後會互相抵消；斜射造成的扁平方向一致，會累加。
- 能力限制：正射影像（Batch1、Batch2）的等效斜射角為 5～19°，因此以影像形狀只能可靠偵測約 25° 以上的斜射。
- 建議：若設備可匯出觀察傾斜角，於配方設定 `"acquisition_limits": {"view_angle_deg": [0, 1]}`，以拍攝參數把關小角度斜射。

### 2.4 配方覆寫範例

```json
"quality_rules": [
  {"metric": "image.snr", "warn_below": 120, "fail_below": 50},
  {"metric": "bump_alignment.sites_used", "warn_below": 50, "fail_below": 20, "kinds": ["raw16", "rgb8"]}
]
```

## 3. 暗場／平場校正

用於扣除偵測器的暗電流與增益不均勻（例如影像四周偏暗）。

### 3.1 建立校正設定檔

1. 在與正式拍攝相同的管電壓與 X 光管模式下，移開樣品，拍攝 5～10 張空拍影像（平場）。
2. 關閉 X 光，拍攝 5～10 張暗場影像（若設備已自行扣除暗場，可省略）。
3. 執行：

```
python -m xrayvision calib-create --id kv90-hr --flat flat/ --dark dark/ --conditions "kv=90,mode=high_resolution"
```

校正設定檔存放於 `calibration/<代碼>/`，包含平均後的平場、暗場與拍攝條件。

### 3.2 使用

於配方設定 `"calibration_profile": "kv90-hr"`。每筆分析結果會記錄使用的校正設定檔。影像尺寸與校正影像不同時，分析會停止並回報錯誤。

## 4. 拍攝參數

### 4.1 來源

1. **手動輸入**：命令列 `--acq "kv=90,power_w=5,frames=8"`（第 3 階段起可於介面輸入）。
2. **參數檔**：與影像同名的 `.json`、`.txt` 或 `.ini`。文字檔每行 `名稱=值` 或 `名稱: 值`。

設備實際匯出的參數格式尚待確認（規劃書 Q1）；目前以通用格式與名稱別名支援：

| 標準名稱 | 可辨識的名稱（不分大小寫、忽略空白與單位括號） |
|---|---|
| `tube_voltage_kv` | kV、Voltage、Tube Voltage、kVp |
| `tube_current_ua` | uA、µA、Current、Tube Current |
| `tube_power_w` | Power、Watt、Tube Power |
| `exposure_ms` | Exposure、Exposure Time、Integration Time |
| `frames` | Frames、Frame Average、Averaging、Integration |
| `tube_mode` | Mode、Tube Mode、Focus Mode |
| `magnification` | Magnification、Mag |
| `view_angle_deg` | View Angle、Tilt、Tilt Angle、Oblique Angle |

無法辨識的名稱保留在 `extra`，不會遺失。

### 4.2 允許範圍

配方可設定 `"acquisition_limits": {"tube_voltage_kv": [60, 110]}`。超出範圍時，品質閘門判為「警告」。

### 4.3 成像條件指紋

沒有拍攝參數時，品質指標（訊雜比、中位亮度、動態範圍、凸塊對比、邊緣模糊寬度）即作為成像條件指紋，記錄於每筆結果，用於追溯與比對。

## 5. 像素尺寸

像素尺寸的決定順序：

1. 配方 `pixel_size_um`（固定值，例如由校正片量得）。
2. 由檢測模組參數 `design_pitch_um`（設計間距）與實測間距推得。

兩者都設定時，平台計算「實測間距 × 像素尺寸」與設計間距的偏差，用來發現放大率變動或配方選錯。所有以 `_px` 結尾的量測值，會同時提供 `_um` 值。

## 6. 量測不變性驗證程序（標準作業程序）

### 6.1 目的

確認拍攝條件改變時，量測結果的變動在容許範圍內，並訂出配方允許的拍攝參數範圍。每個檢測模組發布前都須完成本驗證。

### 6.2 取像

1. 選一顆代表性樣品，固定於載台，**全程不移動樣品與載台**。
2. 依下表拍攝（每組條件至少 2 張），並記錄每張的拍攝參數（參數檔或手動輸入）：

| 組別 | 管電壓 | 功率 | 說明 |
|---|---|---|---|
| A | 常用值 | 常用值 | 基準 |
| B | 常用值 | 常用值 × 0.5 | 功率變動 |
| C | 常用值 | 常用值 × 1.5（不得飽和） | 功率變動 |
| D | 常用值 − 20 kV | 調整至亮度相近 | 管電壓變動 |
| E | 常用值 + 20 kV | 調整至亮度相近 | 管電壓變動 |

### 6.3 執行

```
python -m xrayvision validate sweep/ --recipe recipes/<配方>.json --tolerance 0.2 --out validation/
```

### 6.4 報告內容

| 段落 | 內容 |
|---|---|
| 各影像結果 | 每張的晶片偏移、標準誤、成像品質、拍攝參數 |
| 影像間差異 | 晶片偏移的張間最大差異，對照容許值判定通過或未通過 |
| 成像條件指紋 | 每張的品質指標 |
| 逐物件重複性 | 兩兩配對同一凸塊，計算重拍雜訊、物件間差異與相關係數 |

### 6.5 判讀

- 張間最大差異 ≤ 容許值：該參數範圍可列入配方的允許範圍。
- 管電壓組（D、E）超出容許值：依管電壓區間建立不同配方，或縮小允許範圍。
- 逐物件相關係數高（> 0.8）：代表量到的是真實結構，而非雜訊。

### 6.6 現有資料的驗證結果

Batch2 的 1.tiff 與 2.tiff 為同一視野重拍，亮度差約 30%、放大率差 0.73%：

- 晶片偏移張間差異 0.076 px（容許 0.2 px）→ **通過**。
- 逐物件重拍雜訊約 0.30 px，物件間差異約 1.1 px，相關係數 0.91～0.93。

此結果尚未涵蓋管電壓變動，需依 6.2 節取得參數掃描影像後補做。
