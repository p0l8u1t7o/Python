## 1. 產品簡介

本產品分析 X 光檢測設備輸出的影像，依配方執行檢測模組並產生判定、疊圖與報告。目前提供的檢測模組：

- 微凸塊對位：量測覆晶封裝微凸塊與基板焊墊的逐點偏移，以及晶片整體偏移。
- 空洞檢測：量測焊球與凸塊內的空洞，逐顆計算空洞率（尚未完成驗證，判定最多列為「需複判」，見第 6.5 節）。

- 本產品不控制 X 光檢測設備，只讀取設備輸出的影像；不會移動、刪除或鎖定設備的影像檔。
- 以 Windows 服務方式在背景執行，開機後自動啟動，不需登入 Windows。
- 使用瀏覽器（Microsoft Edge 或 Google Chrome）操作，網址為 `http://127.0.0.1:8600/`；只接受本機連線。
- 介面支援繁體中文與英文，並提供亮色與暗色主題，可於畫面右上角切換。

### 1.1 系統需求

| 項目 | 需求 |
|---|---|
| 作業系統 | Windows 10（1809 以上）或 Windows 11，64 位元 |
| 處理器與記憶體 | 4 核心以上、8 GB 以上（建議 16 GB） |
| 磁碟空間 | 程式約 300 MB（每保留一個版本另需約 300 MB）；資料依影像量而定，16-bit 原始影像每張約 12 MB |
| 螢幕 | 1920×1080 以上 |

### 1.2 角色

| 角色 | 可執行的工作 |
|---|---|
| 操作員 | 檢視總覽與紀錄、匯入影像、重新分析、人工複判、列印報告 |
| 工程師 | 操作員的全部工作，以及配方管理、資料夾監看、問題回報包、稽核紀錄 |
| 系統管理員 | 工程師的全部工作，以及帳號管理、軟體授權、資料保留、軟體更新與退版 |

## 2. 安裝

1. 以具有 Windows 系統管理員權限的帳號登入。
2. 執行 `X-RayVision-<版本>-setup.exe`，依畫面指示完成安裝。預設安裝位置為 `C:\Program Files\X-RayVision`，資料存放於 `C:\ProgramData\X-RayVision`。
3. 安裝程式會註冊並啟動「X-RayVision Inspection Service」服務，並執行內建自我檢查（約 1 分鐘）。
4. 完成後勾選「開啟 X-RayVision」，或由開始功能表開啟。

注意事項：

- 一台電腦只能安裝一份。已安裝時安裝程式會拒絕執行；升級請使用網頁的「軟體更新」功能（第 8 節）。
- 若電腦安裝了防毒或端點防護軟體，建議將以下位置加入排除清單，避免掃描影響分析效能或攔截更新：
  - `C:\Program Files\X-RayVision\`
  - `C:\ProgramData\X-RayVision\`
- 本產品不會安裝或修改系統的 Python、Node.js 或其他共用元件，也不會修改 X 光檢測設備軟體的目錄。

## 3. 首次設定

依序完成以下設定後即可開始使用。

| 步驟 | 執行者 | 畫面 | 說明 |
|---|---|---|---|
| 1 | 安裝人員 | 建立系統管理員 | 首次開啟時出現，建立第一個系統管理員帳號 |
| 2 | 系統管理員 | 系統管理 > 軟體授權 | 啟用授權（第 4 節）；未啟用前無法分析 |
| 3 | 系統管理員 | 帳號管理 | 建立工程師與操作員帳號 |
| 4 | 工程師 | 配方管理 | 建立並發布配方（第 6 節） |
| 5 | 工程師 | 資料夾監看 | 指定設備輸出影像的資料夾（第 5.2 節） |
| 6 | 系統管理員 | 系統管理 > 資料與儲存空間 | 視需要設定封存影像保留天數（第 7 節） |

### 3.1 帳號

- 新帳號由系統管理員於「帳號管理」建立並設定初始密碼；使用者首次登入時必須變更密碼。
- 密碼至少 8 個字元。連續輸入錯誤 5 次，帳號鎖定 5 分鐘；系統管理員可「重設密碼」立即解除鎖定。
- 離職或不再使用的帳號請「停用」，不要刪除，以保留稽核紀錄中的操作人員。
- 系統至少須保留一位啟用中的系統管理員。
- 閒置 12 小時後需重新登入。個人密碼可於右上角帳號選單「變更密碼」。

## 4. 軟體授權

本產品採訂閱授權，一份授權限用於一台電腦。授權的啟用、續約與移轉全程不需連網。

### 4.1 啟用與續約

1. 系統管理員進入「系統管理」，於「軟體授權」按「下載授權申請檔」，取得 `license_request_<機器碼>.xrvreq`。
2. 將申請檔交給原廠（電子郵件或隨身碟）。
3. 原廠回覆授權檔（`.xrvlic`）後，按「匯入授權檔」選取該檔案。
4. 畫面顯示授權客戶、訂閱期間、寬限天數與可用檢測模組，狀態為「授權有效」即完成。

續約時重複相同步驟，匯入新的授權檔即可，不需停止服務。

### 4.2 到期提醒與寬限期

- 到期前 30、14、7、1 天起，所有使用者畫面上方會顯示提醒。
- 到期後若授權檔含寬限天數，寬限期內仍可分析，並持續顯示警示。
- 寬限期結束後停止新的分析：資料夾監看的新影像會保留在等待狀態，續約後自動處理；檢視、報告、匯出與問題回報包仍可使用。

### 4.3 硬體變更與移轉

- 授權綁定電腦硬體特徵產生的機器碼。更換單一零件通常不影響授權；若狀態顯示「授權與本電腦不符」，請重新下載申請檔交給原廠。
- 更換電腦時：在舊電腦按「停用授權（移轉）」並保存下載的停用證明檔（`.xrvdeact`），連同新電腦的申請檔交給原廠辦理。停用後舊電腦立即停止分析，此操作無法復原。
- 請勿將系統時間調回過去。系統時間早於既有紀錄時，授權狀態會顯示「系統時間異常」並停止分析，校正時間後即恢復。

## 5. 日常作業

### 5.1 檢測總覽

登入後的首頁，顯示今日檢測數量、待複判數量、分析佇列、近 14 天判定統計、待複判清單與最近檢測。

### 5.2 影像來源

**資料夾監看（建議）**：工程師於「資料夾監看」新增設備輸出影像的資料夾並選擇配方。系統定時掃描，檔案寫入完成、大小穩定後才讀取，並以複製方式封存，不影響設備軟體。

- 批號預設為影像所在的上一層資料夾名稱；也可設定命名規則，從檔名解析批號與樣品編號。
- 「匯入資料夾內既有影像」未勾選時，只處理新增的影像。
- 按「立即掃描」可不等待下一次定時掃描。

**手動匯入**：於「影像匯入」選擇配方、輸入批號後上傳影像檔。

### 5.3 判定結果

| 判定 | 說明 |
|---|---|
| 合格 | 量測結果（含量測不確定度）在規格內 |
| 不合格 | 量測結果超出規格 |
| 需複判 | 結果接近規格邊界、有效量測點不足、有焊點無法量測、影像為 8-bit 轉存影像（非原始影像，僅供參考），或檢測模組尚未完成驗證 |
| 影像品質不足 | 成像品質未達配方要求（例如過暗、模糊、斜射影像），不輸出量測判定 |
| 未判定 | 配方未設定判定規格 |

### 5.4 檢閱與人工複判

「檢測紀錄」左側為清單、右側為預覽（影像與疊圖、判定、主要量測值、判定原因），可快速瀏覽多張影像：

| 操作 | 說明 |
|---|---|
| 點選清單 或 ↑ ↓ | 切換預覽的影像；到頁尾自動換頁 |
| Enter 或 雙擊 | 開啟完整檢閱畫面 |
| 空白鍵 | 勾選目前這筆（供批次重新分析、匯出問題回報包） |
| 右上「表格」 | 改為表格檢視 |

預設只顯示每張影像的**目前結果**（最新一筆）；取消勾選「僅顯示目前結果」可看到重新分析前的舊紀錄，舊紀錄標示「已被取代」。

1. 於「檢測紀錄」篩選日期、批號、判定，選取紀錄後按「檢閱」（或 Enter）開啟檢閱畫面；檢閱畫面的「上一張／下一張」依清單順序切換，「返回紀錄」回到清單原位置。
2. 影像上的疊圖顯示凸塊、焊墊與偏移向量；可縮放、平移並切換疊圖。
3. 右側分頁顯示判定、晶片偏移、成像品質、拍攝參數與版本資訊。
4. 需要人工確認時，選擇複判結果並填寫「複判說明」，按「送出複判」。複判紀錄會保留原判定與所有複判歷程。

### 5.5 報告與匯出

- 檢閱畫面按「檢測報告」開啟 A4 報告，可列印或另存 PDF。
- 「檢測紀錄」可將篩選結果匯出為 CSV。

### 5.6 重新分析

配方更新或需要重新計算時，可重新分析：

- 單張：於預覽或檢閱畫面按「重新分析」。
- 多張：於「檢測紀錄」勾選後按「重新分析」。
- 配方新版本發布時，可在發布對話框直接選擇重新分析的範圍（第 6 節）。

預設使用各紀錄所用配方的最新發布版本，也可指定其他已發布版本。新結果完成後成為該影像的**目前結果**，原紀錄保留於「分析歷程」分頁並標示「已被取代」。新結果重新自動判定，**不沿用**舊紀錄的人工複判；舊的複判可在分析歷程中參考。影像檔已依保留天數刪除的影像無法重新分析，會列出並略過。「影像匯入」頁顯示重新分析進度，可取消剩餘工作。

## 6. 配方管理（工程師）

配方定義使用的檢測模組、量測參數、判定規格、成像品質規則與拍攝參數允許範圍。

- 新配方為「草稿」，可自由修改；確認後按「發布」。**發布後內容不可修改**，並鎖定檢測模組版本，確保同一配方的結果可追溯。
- 需要調整已發布的配方時，按「修改」：系統以該版本內容建立下一版草稿（已有草稿時直接開啟）。編輯器頂端顯示「修改自 vN」，可展開檢視變更的項目。
- **試跑**：編輯器下方的「試跑」可選一張已分析的影像，以目前編輯中（含尚未儲存）的內容分析，並與該影像的目前結果並列比較。試跑不產生檢測紀錄，可反覆調整參數後再發布。
- 草稿按「發布」時，對話框列出與來源版本的差異，並選擇發布後重新分析的範圍：
  - 使用此配方舊版本的全部影像（預設），顯示影像數與預估時間；
  - 指定批號；
  - 不重新分析（只套用於之後的新影像）。
- 資料夾監看自動使用最新發布的版本，發布後不需修改監看設定。
- 不再使用的配方按「停用」；既有紀錄不受影響。
- 判定規格（例如晶片偏移上限）以 µm 設定時，需在配方設定像素尺寸，或設定設計間距由系統推得。
- 預設參數適用多數情況；「顯示進階參數」中的項目建議依原廠建議調整。

### 6.1 空洞檢測配方

- **焊點半徑搜尋範圍須依產品設定**，只涵蓋要檢測的焊點種類（例如 BGA 錫球）。範圍同時包含其他結構（微凸塊、與多個焊墊重疊的凸塊）時，可能出現誤報或大量「無法量測」的焊點。半徑可在檢閱畫面點選焊點後，於「物件」分頁查看。
- 預設判定規格為單顆空洞率 25%；可另設定最大單一空洞、總空洞率與允許超規焊點數。
- 空洞率接近規格、無法量測的焊點、空洞與焊墊重疊（旗標「空洞與焊墊重疊」）時，判定列為「需複判」，請於檢閱畫面確認。
- 檢閱畫面與報告列出空洞率最高的焊點與空洞率分布；判定原因標示是第幾顆焊點。

### 6.2 檢測區域

配方可限定檢測範圍，例如只檢測晶片下方的焊點、排除定位記號或其他結構：

1. 在配方編輯畫面的「檢測區域」選擇一筆檢測紀錄的影像作為參考影像。
2. 選擇形狀（矩形或多邊形）與區域類型（包含或排除），在影像上框選。矩形以拖拉繪製；多邊形逐點點選，連按兩下完成。
3. 儲存草稿並發布。

檢測模組只處理中心位於包含區域內、且不在排除區域內的目標；未設定包含區域時為整張影像。區域以參考影像的像素座標儲存；分析影像尺寸不同時依比例縮放，並在檢閱畫面提示確認。樣品擺放位置變動較大時，請重新框選。檢閱畫面的「檢測區域」圖層可顯示區域框線。

### 6.3 深度學習模型

空洞檢測可選擇以深度學習模型分割空洞（參數「空洞分割方法」：規則式、深度學習模型、兩者並用）。

1. 原廠提供模型檔（`.xrvmodel`，已簽章）。工程師於「配方管理 > 深度學習模型」按「匯入模型檔」。
2. 在配方的「深度學習模型」選擇模型，「空洞分割方法」選「深度學習模型」或「兩者並用」，發布配方。
3. 「兩者並用」時，規則式與模型的空洞率差異超過 3 個百分點的焊點列為需複判，並採用較大的空洞率。

停用的模型不能用於新發布的配方，已發布的配方仍可執行。

推論預設使用 CPU。X 光檢測設備可能使用 GPU 進行 3D 重建，系統管理員確認不影響設備操作後，可於「系統管理 > 深度學習推論」啟用 GPU。

### 6.4 空洞標註與訓練資料

工程師可修正空洞的正確位置，作為模型訓練與模組驗證的正確答案：

1. 在檢閱畫面按「標註」開啟標註頁。畫面預先顯示檢測結果的空洞。
2. 工具：「畫空洞」逐點點選輪廓，連按兩下或 Enter 完成；「選取」點選輪廓後按 Delete 刪除；「清除焊點空洞」點選焊點移除其中所有空洞。滾輪縮放，按住 Shift 拖曳平移。
3. 按「儲存」。每次儲存都保留歷程；標註不會改變檢測紀錄的判定。
4. 在「檢測紀錄」勾選已標註的紀錄，按「匯出訓練資料」，將檔案交給原廠。勾選「包含原始影像與整張標註」時可作為模組驗證資料集。

### 6.5 檢測模組驗證

檢測模組的每個版本須經驗證核准，才能輸出正式的合格／不合格判定；未驗證模組的判定最多列為「需複判」，紀錄與報告註記「檢測模組尚未驗證」。

1. 以實際樣品影像完成檢出率、誤判率、成像條件不變性與重複性驗證。
2. 工程師於「配方管理 > 檢測模組」按「核准驗證」，填寫說明（驗證影像集、結果摘要）與驗證報告編號。
3. 核准後的新分析即輸出正式判定；已完成的紀錄不變，需要時可「重新分析」。
4. 發現問題時可「撤銷核准」。核准與撤銷都記錄於稽核紀錄。

核准以「主版.次版」為單位；軟體更新只提升修訂版號時沿用原核准，次版號提升時須重新驗證。

## 7. 資料保留與儲存空間（系統管理員）

「系統管理 > 資料與儲存空間」顯示資料目錄、磁碟剩餘空間與目前設定。

- **封存影像保留天數**：預設不自動刪除。設定天數後，系統每小時刪除超過天數的封存影像檔；檢測紀錄、結果、報告資料與稽核紀錄全部保留，但檢閱畫面將無法顯示影像。
- **剩餘空間警示門檻**：預設 20 GB。低於門檻時所有使用者畫面上方顯示警示，請清理空間或設定保留天數。
- 設備原始輸出資料夾的影像不受本產品的保留設定影響，請依設備管理規定處理。

## 8. 軟體更新與退版（系統管理員）

更新檔（`.xrvupd`）由原廠提供，已經原廠數位簽章；經過修改或損毀的檔案無法安裝。

### 8.1 進版

1. 確認沒有進行中的分析（總覽的分析佇列為 0）。
2. 「系統管理 > 軟體更新」按「上傳更新檔」，選取 `.xrvupd`。系統驗證簽章、內容與版本相容性。
3. 驗證通過後按「開始進版」並確認。
4. 服務暫停數分鐘，期間網頁無法使用。系統依序執行：停止服務、建立資料快照、切換版本、啟動、自我檢查。
5. 自我檢查通過即完成；**若失敗，系統會自動還原快照並退回原版本**，並在版本歷史記錄原因。

系統保留最近 3 個版本，供退版使用。

### 8.2 退版

1. 「已安裝版本」列出可退回的版本，按「退回 <版本>」並確認。
2. 系統將資料還原至當初升版前的快照，並切換回該版本。
3. **升版之後新增的檢測紀錄不會顯示在退回後的版本中**，而是保存為「退版封存檔」。日後升級到相容版本時，可在「退版封存檔」清單按「匯入」合併回來。

### 8.3 授權與更新

授權無效或已到期時無法安裝更新，請先續約。

## 9. 問題回報包

對分析結果有疑慮時（例如疑似漏檢、結果與預期不符），可將相關紀錄打包成單一檔案交給原廠分析。

1. 於「檢測紀錄」勾選相關紀錄，按「匯出問題回報包」。
2. 填寫「問題描述」，說明疑慮的位置或預期結果。
3. 選擇選項：
   - 包含原始影像：原廠需要影像才能重現問題，建議勾選。
   - 去識別化：以代號取代批號、檔名與人員名稱。
   - 加密：只有原廠可以開啟。
   - 分割大小：檔案需以電子郵件傳送時設定。
4. 下載產生的檔案交給原廠。匯出紀錄可於「問題回報」頁查詢。

回報包內含原始影像、分析結果、配方、軟體與模組版本、執行紀錄，不含帳號密碼與授權金鑰。

## 10. 稽核紀錄（工程師、系統管理員）

登入、帳號、配方、匯入、複判、授權、設定、更新與退版等操作，都記錄操作人員、時間與內容。稽核紀錄只能新增，無法修改或刪除。

## 11. 解除安裝

於 Windows「設定 > 應用程式」解除安裝 X-RayVision。服務與程式會被移除，**資料目錄 `C:\ProgramData\X-RayVision` 會保留**（檢測紀錄、影像、授權與設定）。確定不再需要時，請自行刪除該目錄。

如需移至其他電腦，請先辦理授權移轉（第 4.3 節）。

## 12. 疑難排解

| 狀況 | 處理方式 |
|---|---|
| 網頁無法開啟 | 開機後服務延遲約 1～2 分鐘啟動，請稍候。仍無法開啟時，於 Windows「服務」確認「X-RayVision Inspection Service」為執行中，或重新啟動電腦 |
| 畫面顯示已停止新的分析 | 依橫幅說明處理授權（第 4 節） |
| 監看資料夾的影像沒有分析 | 確認配方已發布、資料夾路徑正確、授權有效；於「資料夾監看」查看失敗數量與原因 |
| 判定為影像品質不足 | 於檢閱畫面的「成像品質」分頁查看未達標的指標，確認拍攝條件（電壓、功率、傾斜角度、對焦） |
| 檢閱畫面顯示影像檔已不存在 | 封存影像已依保留天數刪除，量測結果仍可檢視 |
| 進版失敗 | 系統已自動退回原版本，資料不受影響。請匯出問題回報包，並附上版本歷史的失敗原因交給原廠 |
| 忘記系統管理員密碼 | 由其他系統管理員重設。沒有其他系統管理員時，見第 12.1 節 |

記錄檔位於 `C:\ProgramData\X-RayVision\logs\`，聯絡原廠時可一併提供。

### 12.1 本機重設帳號密碼

沒有其他系統管理員可重設密碼時，可在本電腦上以指令重設：

1. 以「系統管理員身分」開啟命令提示字元。
2. 執行（`<版本>` 為目前版本，可於 `C:\Program Files\X-RayVision\versions` 查看）：

   ```
   "C:\Program Files\X-RayVision\versions\<版本>\python\python.exe" -m xrayvision reset-password <帳號> --data C:\ProgramData\X-RayVision
   ```

3. 畫面顯示一次性密碼。以該密碼登入後，系統會要求設定新密碼。

此指令同時解除鎖定並重新啟用該帳號，並記錄於稽核紀錄（操作人員為 `local-console`）。

### 12.2 啟動與停止服務

服務在開機後自動啟動，一般不需手動操作。需要暫停分析（例如設備電腦維護）或重新啟動服務時，使用開始功能表「X-RayVision」資料夾內的捷徑：

| 捷徑 | 用途 |
|---|---|
| 啟動服務 | 啟動服務，並等候網頁可以開啟 |
| 停止服務 | 停止服務；進行中的分析會中止，重新啟動後自動重新排入佇列 |
| 重新啟動服務 | 停止後再啟動 |
| 服務狀態 | 顯示服務是否執行中與網頁位址 |

啟動、停止與重新啟動需要系統管理員權限，執行時會出現 Windows 使用者帳戶控制確認視窗。相同的腳本位於 `C:\Program Files\X-RayVision\service\`。停止服務期間，資料夾監看不會匯入新影像，重新啟動後會補匯入。
