## 1. 需求與決議（2026-10-14）

客戶需求：

1. 每張影像拍的是晶片（Die）的不同位置。以晶片的左上角、右下角等角點位置定位，角點可**自動辨識**，也可**在配方中手動圈選位置**。以四個角點換算對角線，計算**整體偏移量**。
2. 以上述方式進行**圖組量測**：圖組的計算與分析**手動、自動都要支援**，並產生報表。

選項討論決議：

| 項目 | 決議 |
|---|---|
| 跨影像的座標關聯 | **兩種都支援**：預設「角點定位＋晶片設計尺寸」（不需設備平台座標）；影像附有平台座標時，以平台座標換算角點的實際位置，並交叉比對 |
| 最少角落數 | **至少一組對角**（左上＋右下，或右上＋左下）；四角齊全時兩條對角線互相驗證 |
| 圖組形成 | 影像匯入後**在介面上拖拉**組成圖組；資料夾監看時依**子資料夾**或**檔名規則**自動分組，由使用者在監看設定中選擇 |
| 樣本影像 | Batch2 是否為同一顆晶片**不確定**；先用 Batch2 開發角點偵測，圖組計算以合成影像驗證，取得客戶圖組影像後再驗證 |

### 1.1 現況

- 微凸塊對位模組在**單張影像內**量測凸塊對焊墊的偏移量，並擬合出該影像的晶片偏移（平移、旋轉、縮放）。單張影像只涵蓋晶片的一小塊時，旋轉的力臂很短，旋轉幾乎量不出來，平移也只代表那一塊。
- 影像之間沒有共同座標：TIFF 沒有拍攝位置，拍攝參數檔目前也沒有平台座標欄位。
- Batch2 的影像中，1、2、4 有晶片左上角，9 有左下角，8 有右下角，5 只有上緣，3、6、7 在晶片中間。晶片本體在吸收量影像中是一塊吸收較高的矩形，邊緣是寬約數十像素的漸變。

### 1.2 對需求的解讀（請確認，見第 9 節 Q1）

- **整體偏移**＝整顆晶片相對基板的**中心平移（dx, dy）＋旋轉**，與現有「晶片偏移」的定義相同，差別在於改用整組影像計算。
- 偏移量本身仍由**凸塊對焊墊**量測，因為它直接代表晶片對基板的位置差，而且精度最高。
- **角點**的用途是把每張影像定位到晶片座標上，讓相隔一條對角線的兩個角落成為旋轉的長力臂。旋轉的精度大約與力臂長度成正比：一張影像約 2,000 px，整顆晶片的對角線可能是它的數倍到十數倍。
- 角點位置誤差對結果的影響很小。角點偏 1 px 時，量測點的位置也只偏 1 px，帶來的偏移誤差約為「旋轉量 × 1 px」，遠小於 0.01 px。所以角點只要穩定，不需要次像素精度。

### 1.3 不變的原則

- 單張影像的分析、判定與紀錄**維持不變**。圖組是建立在單張結果之上的另一層，不改寫單張結果。
- 已發布配方不可修改；圖組設定屬於配方內容，修改後以新版本發布。
- 紀錄只新增：重新計算圖組時產生新的圖組結果，舊結果標示「已被取代」，比照 PLAN-003 的單張結果。
- 既有配方沒有啟用圖組量測，分析結果與回歸基準**完全不變**。

## 3. A　晶片角點偵測

### 3.1 自動偵測

新增平台核心 `core/die_corner.py`，屬於平台的「影像定位」能力，之後其他模組也能使用：

1. 吸收量影像先**抹除凸塊與錫球**：以已偵測的圓形物件（或形態學開運算）換成鄰近背景，避免它們干擾邊緣。
2. 以大尺度平滑取得「晶片本體／基板」兩個亮度平台，計算梯度。
3. 在搜尋區域內找出水平與垂直的晶片邊緣點，用穩健直線擬合（RANSAC，再以邊緣輪廓半高位置精修）得到兩條邊。
4. 兩條邊的交點就是**角點**。晶片本體落在交點的哪個象限，決定這是**左上／右上／左下／右下**哪個角。兩條邊的方向也一併輸出，即**晶片邊緣角度**。
5. 品質指標包括邊緣對比、擬合殘差、兩邊夾角與 90° 的差。不符合時回報「未偵測到角點」並附原因代碼，不硬給結果。

角點搜尋範圍：配方有圈選角點搜尋區域時只在區域內找，沒有時找整張影像。只有一條邊（例如 Batch2 的 5.tiff）或沒有邊（中間的影像）時，該影像標示為「非角落影像」。

### 3.2 配方中圈選角點位置

配方新增「圖組量測」區塊，角點搜尋區域的操作沿用 PLAN-004 的 `RegionCanvas`：

- 每個角落（左上、右上、左下、右下）可各圈一個**角點搜尋區域**（矩形），以參考影像尺寸記錄，影像尺寸不同時依比例縮放，與檢測區域規則相同。
- 可指定該區域的角落位置。指定後，即使自動判斷結果不同，也以指定為準，並記錄在結果中。
- 工程師在參考影像上圈選後可以立即試跑，看到角點與兩條邊的疊圖。

### 3.3 單張影像手動指定角點

自動偵測失敗或不準時，工程師以上的角色可以在檢閱頁**手動指定角點**：拖曳角點，並以兩條邊的方向線對齊晶片邊緣。

- 比照「自訂檢測區域」：手動角點記錄在影像上（操作者、時間、原值），之後重新計算圖組時預設沿用，稽核紀錄可查。
- 手動角點只影響圖組計算，單張影像的對位結果不變。

### 3.4 模組與版本

- 角點偵測屬於平台能力（`core/die_corner.py`、`core/image_set.py`），由分析流程在配方啟用圖組量測時執行。結果記錄在分析結果的 `die_corner`：角點、角落位置、邊緣角度、品質與來源（自動／配方搜尋區域／手動）。檢測模組的量測與版本都不變。
- 未啟用圖組量測的配方不偵測角點，回歸比對必須 0 差異。
- 實作時確認的做法：
  - 開運算的結構元素與平台亮度一律以整張影像計算，搜尋區域只用來篩選邊緣點與角點，因此兩種搜尋方式的結果一致（差 ≤ 8 px）；
  - 每一類邊緣最多擬合 3 條線，供多晶片封裝使用；
  - 外側以緊鄰邊緣的窄帶檢查，相鄰晶片之間的基板帶很窄也能判對。

## 4. B　圖組計算引擎

### 4.1 輸入

圖組中每張影像的單張結果，包括逐點偏移量、各點位置、角點與角落位置；有平台座標時另加平台座標。

### 4.2 座標模式一：角點定位＋晶片設計尺寸（預設）

- 配方填入**晶片設計尺寸**（寬 × 高，µm 或 px；以 µm 填寫時需有像素尺寸）。
- 晶片座標以晶片中心為原點，軸向沿晶片邊緣。四個角的名目位置為（±W/2, ±H/2）。
- 角落影像中，每個量測點依「相對角點的位置，扣掉晶片邊緣角度旋轉」換算到晶片座標；偏移向量做同樣的旋轉。
- 只有角落影像參與整體計算。非角落影像保留單張結果，在圖組中顯示為「未定位」。

### 4.3 座標模式二：平台座標

- 拍攝參數新增 `stage_x_um`、`stage_y_um`（別名對應比照現有拍攝參數，例如 `x`、`stagex`、`posx`），可從同名參數檔讀取或手動輸入。
- 配方設定平台軸向：X/Y 是否反向、是否互換，並需要像素尺寸。
- 每張影像的量測點以「平台座標＋（像素位置 − 影像中心）× 像素尺寸」換算到共同座標。這個模式下**非角落影像也能參與計算**。
- 角點換算出實際位置後，求出兩條對角線的實測長度、晶片實測尺寸與晶片中心，再與設計尺寸**交叉比對**。差異超過容許值時列為需複判，通常代表分組錯誤或角點偵測錯誤。

### 4.4 整體偏移

- 所有參與點以最小平方法擬合 `偏移量 = t + ω × 位置`（加上穩健剔除），得到：
  - **整體晶片偏移 t（dx, dy）**：晶片中心的平移，附標準誤；
  - **晶片旋轉 ω**；縮放預設不擬合，可在進階參數開啟。
- **對角線驗證**：每條完整的對角線（左上－右下、右上－左下）各自計算一次旋轉與中心平移。四角齊全時比較兩條對角線的結果，差異超過容許值（配方參數）時列為需複判。
- 另外輸出各角落的平均偏移量，報告中以示意圖呈現。

### 4.5 判定

圖組判定的優先順序比照單張影像：

| 狀況 | 圖組判定 |
|---|---|
| 沒有任何一組完整對角 | 需複判（原因：角落不足，無法計算） |
| 有成員影像成像品質不足，而且它是對角線所需的角落 | 影像品質不足 |
| 整體偏移 \|t\| ± k·se 超出上限，或旋轉超出上限 | 不合格 |
| 接近上限、兩條對角線不一致、平台座標交叉比對不符 | 需複判 |
| 其他 | 合格 |

- 規格參數：整體偏移上限（µm／px）、旋轉上限（°）、對角線一致性容許值、尺寸比對容許值、信心倍數 k。
- 微凸塊對位模組目前已核准驗證；圖組計算是新功能，取得客戶圖組影像並驗證之前，圖組判定的合格／不合格**一律改為需複判**，比照空洞模組的未驗證規則。核准方式沿用「配方管理 > 檢測模組」。
- 人工複判比照單張影像，記錄在圖組上。

### 4.6 模組介面擴充

- 檢測模組介面新增可選的 `aggregate_set(members, set_params)`，由微凸塊對位模組實作。其他模組不實作時，不提供圖組計算。
- 檢測模組介面規格（SPEC-001）與模組開發指南（GUIDE-001）同步更新。

### 5.2 圖組頁（新選單：檢測 > 圖組）

畫面比照紀錄頁，左側清單、右側預覽：

- **清單**：圖組編號、批號、成員數、角落覆蓋（四格小圖示，有偵測到的角亮起）、整體偏移、判定。
- **預覽**：**晶片示意圖**。以矩形表示晶片，四角放置角落影像縮圖，標出角點、各角平均偏移向量（可調放大倍率）、對角線與整體偏移向量。下方是成員表。

**拖拉分組**（手動）：

```
┌ 未分組影像（依批號／日期篩選）┐   ┌ 圖組 D-001 ───────────────┐
│ [縮圖] 1.tiff   左上         │   │  左上 [1.tiff]  右上 [ 空 ] │
│ [縮圖] 8.tiff   右下         │ ⇒ │  左下 [9.tiff]  右下 [8.tiff]│
│ [縮圖] 3.tiff   非角落       │   │  未定位：3.tiff             │
└──────────────────────────────┘   │  [計算圖組]                 │
                                   └─────────────────────────────┘
```

- 從未分組清單把影像拖到圖組卡片。影像依自動偵測的角落位置放進對應格子，拖到其他格子即為手動指定角落位置。
- 可以新增、改名、刪除圖組（已計算的圖組只能停用，不刪除），也可以多選後一次拖入。
- 紀錄頁勾選多張影像後，可以「建立圖組」。
- 計算前檢查是否至少有一組對角；不足時按鈕旁顯示缺哪個角。

**圖組檢閱**：完整的晶片示意圖，點選角落即開啟該張影像的檢閱頁（含角點疊圖、手動指定角點）。另有對角線驗證表、平台座標交叉比對表、計算歷程（含已被取代的結果）、人工複判。

## 6. D　自動分組與手動試算

### 6.1 資料夾監看分組規則

資料夾監看設定新增「圖組規則」：

| 選項 | 行為 |
|---|---|
| 不分組（預設） | 維持現狀 |
| 一個子資料夾為一組 | 同一個子資料夾內的影像屬於同一圖組，圖組名稱取資料夾名稱 |
| 依檔名規則 | 正規表示式具名群組 `set`（必要）與 `pos`（選填，角落代碼，例如 TL／TR／BL／BR，可自訂對應） |

- **何時計算**：組內最後一張影像分析完成後，經過「圖組穩定時間」（預設 60 秒）沒有新影像，就自動計算。配方有設定「每組張數」時，張數到齊立即計算。
- 已計算的圖組後來又有影像加入時，自動重算，舊結果標示已被取代。
- 檔名規則提供即時預覽：輸入規則後列出目前資料夾中的檔案會被分成哪幾組。

### 6.2 手動檢測工作區

- 工作區中的影像也可以拖拉成圖組並試算，結果只留在工作區、不寫入正式紀錄，用來調整角點搜尋區域、晶片尺寸與規格。
- 圖組設定可以隨參數組另存為配方草稿。

## 7. E　圖組報告

- **A4 圖組報告**：圖組資訊（批號、配方、成員、角落覆蓋）、整體偏移與旋轉（含標準誤）、判定與原因、晶片示意圖、對角線驗證表、各角落偏移表、成員影像摘要（各自的判定與成像品質）、軟體與模組版本、結果雜湊。繁中／英文依介面語系。

## 11. G　CAD 匯入與疊合（座標模式三，v0.3 新增）

### 11.1 需求與決議（2026-10-14）

客戶需求：直接匯入 CAD，把 CAD 與拍攝影像疊合（mapping），計算整體偏移；影像對位到 CAD 的操作要直覺化。

| 項目 | 決議 |
|---|---|
| 格式 | 座標表（CSV／Excel）、DXF、GDSII／OASIS、Gerber／ODB++ 都要支援，分期交付 |
| 疊合方式 | 自動對位；不對時在影像與 CAD 上各點兩個對應點重新對位，也可以直接拖曳、旋轉微調 |
| 偏移基準 | **焊墊對位到 CAD**，再量每顆凸塊相對 CAD 名目位置的偏離，擬合晶片平移與旋轉 |
| 規劃 | 併入本規劃書，成為圖組量測的座標模式三，共用圖組頁、計算引擎與報告 |

模式三的好處：每顆凸塊都有 CAD 上的身分，不靠局部影像配對焊墊，所以焊墊與凸塊**完全分離時也能計算**。這同時解決 PLAN-007 第 2.3 節「偏移超過半個 pitch」的配對歧義。

### 11.2 CAD 匯入

| 期別 | 格式 | 解析方式 | 說明 |
|---|---|---|---|
| G1 | 座標表 CSV／Excel | 標準函式庫 `csv`；Excel 用 `openpyxl` | 欄位對應精靈：編號、X、Y、直徑、種類（凸塊／焊墊） |
| G1 | DXF | `ezdxf` | 圖層與圖塊清單；圓、圖塊插入點、聚合線外框 |
| G2 | GDSII／OASIS | `gdstk` | 指定圖層／資料型別；多邊形取中心與等效直徑 |
| G3 | Gerber（RS-274X）／ODB++ | Gerber 用 `gerbonara`；ODB++ 自行解析 features 檔 | 指定焊墊層；ODB++ 為壓縮的文字檔 |

- 新套件須確認授權並固定版本，加入 `runtime-requirements.txt`，跑完整測試與冒煙測試。授權初步評估：ezdxf MIT、gdstk BSL-1.0、openpyxl MIT、gerbonara Apache-2.0。
- **匯入精靈**：上傳檔案後列出圖層、圖塊與預覽。使用者把圖層（或欄位）指定為下列角色：
  - **凸塊**（晶片側）
  - **焊墊**（基板側）
  - **晶片外框**
  - **定位標記**（選填）

  另外設定單位（µm、mm、mil、inch）、原點、Y 軸方向（CAD 通常 Y 向上，影像 Y 向下），以及**晶片側是否鏡像**：覆晶時晶片面朝下，晶片側的設計圖從上方看是鏡像。
- 凸塊和焊墊依編號配對；沒有編號時，以 CAD 名目位置最近者配對。數量不一致或配對距離過大時列出清單，請使用者確認。
- 匯入結果存成 **CAD 模型**：只新增、有版本、記錄來源檔雜湊與匯入設定。配方引用 CAD 模型的版本，比照模型管理。資料庫新增 `cad_models` 表。

### 11.3 影像對位到 CAD

每張影像對 CAD 求一個相似變換（像素尺寸、旋轉、平移），必要時可改為仿射變換。

**自動對位**（依序嘗試，取對位殘差最小者）：

1. **初始位置**：
   - 晶片角點（A）對應到 CAD 外框的同一個角；
   - 平台座標（模式二）；
   - 同一配方上一張同位置影像的對位結果。
2. **精修**：把影像中偵測到的焊墊與 CAD 焊墊做點集配對（RANSAC 加上迭代最近點），求最佳變換。焊墊是週期排列，只靠點集會有整數格位的歧義，所以初始位置必須先把誤差縮到半個 pitch 以內。陣列邊界、晶片外框、定位標記都可以用來消除歧義。
3. **品質**：配對的焊墊數、對位殘差 RMS、未配對比例。品質不足時標示「需手動對位」，該影像不參與計算。

**手動對位（介面）**：

```
┌ CAD 畫布 ─────────────────────────────────────┐  ┌ 影像清單 ─────────┐
│  CAD 外框與焊墊（綠）、凸塊名目位置（藍）       │  │ ● 1.tiff 自動 0.6px │
│  ┌──────┐ 影像以半透明疊在 CAD 上             │  │ ● 8.tiff 自動 0.8px │
│  │ 影像 │ ← 拖曳移動；角落把手旋轉            │  │ ▲ 9.tiff 需手動對位 │
│  └──────┘                                      │  └────────────────────┘
│  [兩點對位] [自動精修] [透明度 ─●─] [復原]     │
└────────────────────────────────────────────────┘
```

- 影像以半透明疊在 CAD 上，透明度可調。可以切換「影像在上／CAD 在上」，以及只顯示外框。
- **拖曳**移動、**角落把手**旋轉。滾輪縮放畫布，滑鼠右鍵平移，比照 `RegionCanvas` 的操作。
- **兩點對位**：在影像上點一點，再在 CAD 上點對應點（游標會吸附到最近的焊墊或凸塊），重複兩次即可解出相似變換，接著自動精修。
- 每張影像顯示對位狀態（自動、手動、需手動對位）與殘差。手動對位會記錄操作者與時間，可以追溯。
- 對位結果會套用在後續同位置的影像上，作為初始位置。

### 11.4 計算

- 焊墊對位到 CAD 之後，影像中量到的凸塊中心換算到 CAD 座標，指派給最近的 CAD 凸塊（距離須小於半個 pitch）。
- 逐顆偏移＝實測凸塊位置 − CAD 凸塊名目位置。以第 4.4 節的方法擬合晶片平移與旋轉，並做對角線驗證、判定。
- 凸塊位置由微凸塊對位模組量測，焊墊在對位階段使用。焊墊與凸塊完全分離時，凸塊仍然由偵測直接取得，不需要局部配對焊墊。
- 圖組判定與報告比照第 4.5 節與第 7 節。報告另加一張 CAD 疊圖，標出各影像位置與放大的偏移向量。

### 11.5 驗證

- 合成圖組產生器（第 8.1 節）同步輸出對應的 CSV 與 DXF。驗收項目：
  - 自動對位殘差 ≤ 1 px；
  - 整體偏移誤差 ≤ 0.05 px；
  - 加入完全分離的情況（偏移 > 凸塊加焊墊半徑）後仍能算對。
- 各格式以客戶提供的範例檔驗收，同時產生單位、鏡像、Y 軸方向錯誤的檔案，確認會被精靈攔下或可以修正。
