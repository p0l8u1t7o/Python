## 1. 技術與部署

| 項目 | 內容 |
|---|---|
| 框架 | React 19、React Router（HashRouter）、TypeScript，Vite 建置 |
| 相依套件 | 僅 react、react-dom、react-router-dom；不使用 UI 元件庫，離線即可建置 |
| 部署 | `npm run build` 產生 `web/dist/`，由後端服務直接提供，產線電腦不需 Node.js |
| 路由 | 網址形如 `/#/runs/5`，深層連結不需伺服器端設定 |
| 語系 | 介面文字與後端共用 `xrayvision/i18n/*.json`（產品文字單一來源）；自動測試檢查前端用到的語系鍵都已翻譯 |
| 型別 | `web/src/api/types.ts` 對應後端 API 與分析結果 JSON |

開發時：

```
python -m xrayvision serve --data D:\XRV        後端（http://127.0.0.1:8600）
cd web && npm run dev                           前端開發伺服器（http://127.0.0.1:5173，/api 轉送後端）
npm run typecheck                               型別檢查
npm run build                                   建置正式版
```

## 2. 視覺設計

- **簡潔**：以資訊為主，每個畫面只放完成工作所需的元素。
- **亮色／暗色主題**：預設跟隨作業系統，可於頂端列手動切換並記住偏好。
- **設計代幣**：顏色、字級、間距、圓角集中定義於 `web/src/styles/theme.css`，兩種主題共用同一組元件。
- **判定顏色**：合格（綠）、不合格（紅）、需複判（橙）、影像品質不足（紫）、未判定（灰），兩種主題下固定，並一律搭配文字。
- **影像檢視區**：中性灰背景，避免主題色影響灰階判讀。
- **寬螢幕**：影像檢閱為「影像＋右側面板」雙欄，影像區隨螢幕寬度延展；支援 1920×1080 以上解析度。

## 3. 畫面

| 畫面 | 路徑 | 內容 |
|---|---|---|
| 檢測總覽 | `/#/` | 今日各判定數、待複判數、分析佇列；近 14 日判定統計圖；待複判與最近檢測清單；監看資料夾狀態。每 10 秒自動更新 |
| 檢測紀錄 | `/#/runs` | 依判定、配方、批號、日期篩選；分頁；勾選後匯出問題回報包；匯出 CSV |
| 影像檢閱與複判 | `/#/runs/{id}` | 見第 4 節 |
| 檢測報告 | `/#/runs/{id}/report` | A4 版面：基本資料、判定與原因、晶片偏移（px／µm）、建議修正量、各陣列結果、疊圖影像、成像品質、最後複判、版本資訊；「列印」可另存 PDF |
| 影像匯入 | `/#/imports` | 選擇配方、批號、拍攝參數後拖放上傳；分析工作清單（每 3 秒更新），可取消或重新執行 |
| 配方管理 | `/#/recipes` | 各配方版本與狀態；發布、停用、刪除草稿、另存新版本 |
| 配方編輯 | `/#/recipes/{id}` | 基本資料、判定規格、量測參數（依模組參數結構自動產生，進階參數可收合）、成像品質規則覆寫、拍攝參數允許範圍；已發布版本唯讀 |
| 資料夾監看 | `/#/watch` | 新增監看資料夾（路徑、配方、命名規則、是否含子資料夾、是否匯入既有影像）；啟用／停用；立即掃描 |
| 問題回報 | `/#/diagnostics` | 匯出紀錄與下載 |
| 稽核紀錄 | `/#/audit` | 依類別篩選；點選列檢視詳細內容 |

頂端列：操作人員名稱（第 4 階段改為登入）、語言、主題。

## 4. 影像檢閱與複判

**影像區**

- 滾輪縮放（以游標為中心）、拖曳平移、雙擊回到全圖。
- 疊圖圖層可個別開關：凸塊、焊墊、偏移向量、未採用、剔除、陣列。
- 疊圖透明度、偏移向量放大倍率（預設 ×10）、亮度、對比可調整；亮度與對比只影響顯示，不影響量測。
- 點選凸塊可在「物件」分頁檢視其量測值，並於影像上反白。
- 疊圖依檢測物件的幾何類型與模組宣告的樣式通用繪製；新增檢測模組時不需修改此畫面。

**右側面板**

| 分頁 | 內容 |
|---|---|
| 結果 | 判定原因；各模組判定、晶片偏移（px／µm）、標準誤、建議修正量、旋轉、縮放、採用位點；像素尺寸與來源；版本與影像雜湊值 |
| 品質 | 每項成像品質指標的數值、警告與不合格門檻、判定 |
| 陣列 | 各陣列的偏移、標準誤、縮放、可信度 |
| 物件 | 點選物件的量測值與標記 |
| 拍攝參數 | 參數來源與數值、校正設定檔 |
| 複判 | 選擇合格／不合格／需複判並填寫說明後送出；複判紀錄 |

操作：檢測報告、重新分析（選擇另一個已發布配方）、匯出問題回報包。
