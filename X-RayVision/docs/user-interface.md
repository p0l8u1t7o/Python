## 1. 技術與部署

| 項目 | 內容 |
|---|---|
| 框架 | React 19、React Router（HashRouter）、TypeScript，Vite 建置 |
| 相依套件 | 僅 react、react-dom、react-router-dom；不使用 UI 元件庫，離線即可建置 |
| 部署 | `npm run build` 產生 `web/dist/`，由後端服務直接提供，產線電腦不需 Node.js |
| 路由 | 網址形如 `/#/runs/5`，深層連結不需伺服器端設定 |
| 語系 | 介面文字與後端共用 `xrayvision/i18n/*.json`（產品文字單一來源）；自動測試檢查前端用到的語系鍵都已翻譯 |
| 型別 | `web/src/api/types.ts` 對應後端 API 與分析結果 JSON |

開發時：

```
python -m xrayvision serve --data D:\XRV        後端（http://127.0.0.1:8600）
cd web && npm run dev                           前端開發伺服器（http://127.0.0.1:5173，/api 轉送後端）
npm run typecheck                               型別檢查
npm run build                                   建置正式版
```

## 2. 視覺設計

- **簡潔**：以資訊為主，每個畫面只放完成工作所需的元素。
- **亮色／暗色主題**：預設跟隨作業系統，可於頂端列手動切換並記住偏好。
- **設計代幣**：顏色、字級、間距、圓角集中定義於 `web/src/styles/theme.css`，兩種主題共用同一組元件。
- **判定顏色**：合格（綠）、不合格（紅）、需複判（橙）、影像品質不足（紫）、未判定（灰），兩種主題下固定，並一律搭配文字。
- **影像檢視區**：中性灰背景，避免主題色影響灰階判讀。
- **寬螢幕**：影像檢閱為「影像＋右側面板」雙欄，影像區隨螢幕寬度延展；支援 1920×1080 以上解析度。

## 3. 畫面

| 畫面 | 路徑 | 內容 |
|---|---|---|
| 檢測總覽 | `/#/` | 今日各判定數、待複判數、分析佇列；近 14 日判定統計圖；待複判與最近檢測清單；監看資料夾狀態。每 10 秒自動更新 |
| 檢測紀錄 | `/#/runs` | 左側清單＋右側預覽（影像與疊圖、判定、主要量測、判定原因）；↑↓ 切換、Enter 進入檢閱、空白鍵勾選；可切換為表格檢視；依判定、配方、批號、日期篩選，預設「僅顯示目前結果」；分頁；勾選後批次重新分析、匯出問題回報包或訓練資料；匯出 CSV（PLAN-003） |
| 影像檢閱與複判 | `/#/runs/{id}` | 見第 4 節 |
| 檢測報告 | `/#/runs/{id}/report` | A4 版面：基本資料、判定與原因、晶片偏移（px／µm）、建議修正量、各陣列結果、疊圖影像、成像品質、最後複判、版本資訊；「列印」可另存 PDF |
| 影像匯入 | `/#/imports` | 選擇配方、批號、拍攝參數後拖放上傳；重新分析進度（完成／總數，可取消剩餘工作）；分析工作清單（每 3 秒更新），可取消或重新執行 |
| 配方管理 | `/#/recipes` | 各配方版本與狀態；發布（發布對話框：與來源版本的差異、發布後重新分析的範圍與預估時間）、停用、刪除草稿、修改（建立或開啟下一版草稿） |
| 手動檢測 | `/#/manual` | 工程師以上。左側工作區影像清單（上傳或從檢測紀錄加入；↑↓ 切換）、中間檢視器（檢視／編輯檢測區域，同尺寸影像切換保持縮放位置）與結果分頁（結果總表、判定與量測、陣列、成像品質）、右側參數表單（勾選模組、判定規格與量測參數、基本資料、品質規則、檢測區域）；「分析」(Ctrl+Enter)、「自動分析」、「分析全部」；由配方帶入（與來源不同的參數以 * 標示）、另存為配方草稿、匯出 ZIP、清空工作區；頂端固定標示「手動檢測（非正式結果）」（PLAN-004） |
| 配方編輯 | `/#/recipes/{id}` | 基本資料、判定規格、量測參數（依模組參數結構自動產生，進階參數可收合）、成像品質規則覆寫、拍攝參數允許範圍；草稿顯示「修改自 vN」與變更清單；「發布」（先儲存未儲存的變更）；試跑面板（以編輯中的內容分析一張影像並與目前結果比較，不產生紀錄）；已發布版本唯讀，提供「修改」 |
| 資料夾監看 | `/#/watch` | 新增監看資料夾（路徑、配方、命名規則、是否含子資料夾、是否匯入既有影像）；啟用／停用；立即掃描 |
| 問題回報 | `/#/diagnostics` | 匯出紀錄與下載 |
| 稽核紀錄 | `/#/audit` | 依類別篩選；點選列檢視詳細內容 |

### 3.1 檢測區域編輯器（PLAN-004 第 3 節）

配方編輯器、手動檢測、檢閱頁「自訂檢測區域」共用 `components/RegionEditor.tsx` 的 `RegionCanvas`，建立在可縮放、平移的 `ImageViewer` 上（`tool` 屬性提供繪製圖層與滑鼠事件）：

- 工具：平移、矩形（拖拉）、多邊形（逐點，連按兩下或 Enter 完成）、選取（拖拉移動、8 個控制點、多邊形頂點拖拉與在邊上連按兩下插入頂點）。
- 右鍵或中鍵拖拉、按住空白鍵拖拉一律平移；Delete 刪除、Esc 取消、Ctrl+Z／Ctrl+Y 復原／重做。
- 區域清單可改名稱、類型、勾選「視為一個陣列」（有啟用模組宣告 `supports_region_arrays` 時才顯示）；「視為一個陣列」的區域以橘色標示，互相重疊時提示。
- 可同時顯示該影像的分析結果疊圖供對照；手動檢測使用 `compact` 版面（區域清單在影像下方）。

### 3.1.1 判定標示與標註筆刷（PLAN-005）

- `buildShapes` 解析各模組判定原因的目標（`…:ballN`、`…:groupN`），新增圖層 `<模組>.judgment`（「判定標示」）：超出規格為不合格色 `#d64545`、其餘為需複判色 `#c98200`；後端 `core/render.py` 的匯出疊圖同樣標示。
- 標註頁新增筆刷與橡皮擦（`components/maskPoly.ts`：遮罩運算、格邊輪廓追蹤、簡化並以面積校正，純運算不依賴 canvas）與復原／重做。

### 3.2 本影像自訂檢測區域（PLAN-004 第 6 節）

檢閱頁「自訂檢測區域」（工程師以上）開啟 `ImageRegionsDialog`：預先填入目前生效的區域，可試跑（不產生紀錄）、套用並重新分析、改回配方區域。使用自訂區域的紀錄在清單、預覽、檢閱頁、分析歷程與報告標示「自訂檢測區域」；發布對話框與批次重新分析對話框可選擇是否沿用。

## 4. 影像檢閱與複判

**影像區**

- 滾輪縮放（以游標為中心）、拖曳平移、雙擊回到全圖。
- 疊圖圖層可個別開關：凸塊、焊墊、偏移向量、未採用、剔除、陣列。
- 疊圖透明度、偏移向量放大倍率（預設 ×10）、亮度、對比可調整；亮度與對比只影響顯示，不影響量測。
- 點選凸塊可在「物件」分頁檢視其量測值，並於影像上反白。
- 疊圖依檢測物件的幾何類型與模組宣告的樣式通用繪製；新增檢測模組時不需修改此畫面。

**右側面板**

| 分頁 | 內容 |
|---|---|
| 結果 | 判定原因；各模組判定、晶片偏移（px／µm）、標準誤、建議修正量、旋轉、縮放、採用位點；像素尺寸與來源；版本與影像雜湊值 |
| 品質 | 每項成像品質指標的數值、警告與不合格門檻、判定 |
| 陣列 | 各陣列的偏移、標準誤、縮放、可信度 |
| 物件 | 點選物件的量測值與標記 |
| 拍攝參數 | 參數來源與數值、校正設定檔 |
| 分析歷程 | 同一影像的所有紀錄（新到舊，最新一筆為目前結果）與各紀錄的人工複判（僅供參考，不沿用） |
| 複判 | 選擇合格／不合格／需複判並填寫說明後送出；複判紀錄 |

操作：返回紀錄（回到清單原位置）、上一張／下一張（依紀錄頁當時的清單順序）、檢測報告、重新分析（預設各紀錄配方的最新發布版本，或指定版本）、匯出問題回報包。已被取代的紀錄頂端提示並連到目前結果。
