## 1. 範圍與現況

- 檢測焊球與凸塊（BGA 錫球、C4 凸塊、微凸塊）內的空洞，逐顆計算空洞率。
- 目前**沒有含空洞的實際影像**（Batch1／Batch2 的焊點都沒有可見空洞）。演算法以依物理模型產生的合成影像開發與驗收，Batch1／Batch2 只用來確認不誤報。
- 模組狀態為「未驗證」：判定最多列為「需複判」。取得客戶實際影像並完成驗證後，由工程師核准（第 6 節）。

## 2. 量測方法

所有門檻都以焊點自身的吸收量與局部雜訊為基準，不使用絕對灰階，因此功率與曝光改變時結果不變（規劃書 PLAN-001 第 3.3 節）。

| 步驟 | 內容 |
|---|---|
| 1. 偵測 | 吸收量影像的尺度空間 LoG 偵測，只保留配方半徑範圍內的圓。大空洞把焊球切開時，最強響應會落在焊墊或殘餘亮區，因此再以典型尺度找回小候選對應的焊球，並在典型尺度補上附近沒有焊點的峰值，避免空洞最大的焊球整顆消失；補上的候選須擬合成功、外形與對比合格、振幅不低於一般焊點中位數的一半，否則視為非焊點（不計入未量測，也不在疊圖上標示） |
| 2. 定位 | 只用焊點邊緣（0.55 R 以外）擬合中心、半徑與振幅。邊緣很少有空洞、也沒有焊墊，不會被內部的亮區或暗區拉偏 |
| 3. 外形模型 | 平面背景 + a·截頂球弦長輪廓（含高斯邊緣模糊）+ 焊墊圓盤。截頂比例與模糊寬度先取部分焊點的中位數；排除空洞後再逐顆微調，以適應同一影像中的不同結構 |
| 4. 焊墊 | 以邊緣擬合模型的殘差找出正斑塊當作焊墊初值，一開始就納入模型；否則焊墊亮區會被吸收進振幅，使焊球其餘部分相對變低而被誤判為空洞 |
| 5. 穩健擬合 | 非對稱最小平方初始化（把模型推向「無空洞的上緣」），再以非對稱穩健權重擬合：負殘差（空洞）在 2.5 倍雜訊外大幅降權，正殘差到 6 倍才降權；雜訊尺度取自正殘差一側，空洞佔焊點三到四成時也不會被墊高 |
| 6. 空洞分割 | 相對殘差 = 殘差 ÷ 焊點中心吸收量。種子：平滑後低於 -max(4 倍雜訊, 0.07)；邊界：延伸到局部峰值深度的 10%（以與影像模糊相當的尺度平滑）；填補被包圍的孔洞；排除邊緣 10% 環帶 |
| 7. 重新擬合 | 排除已找到的空洞區後重新擬合、重新分割，直到空洞面積穩定（最多 3 次） |
| 8. 物理合理性 | 細長新月形（內切圓小於等效半徑 0.45 倍）、比同面積球形氣泡淺得多的寬淺凹陷（< 0.4 倍）、貼邊的小區域（< 2%）不計為空洞。兩個以上又深的貼邊區域、或貼邊且深度接近全厚度的大區域，表示焊點實際輪廓與模型不符（複合結構），此焊點不量測 |
| 9. 量測 | 空洞率（空洞總面積 ÷ 焊點投影面積）、最大單一空洞、空洞數、估計誤差；有像素尺寸時同時輸出 µm、µm² |

### 2.1 估計誤差

| 來源 | 計算 |
|---|---|
| 輪廓位置 | 空洞周長 × 0.5 px ÷ 焊點面積 |
| 空洞與焊墊重疊 | 焊墊被空洞遮住的部分會抵消空洞深度，且無法由影像還原。空洞與偵測到的焊墊相接或重疊時，或同一影像多數焊點都有焊墊、此焊點有空洞卻找不到焊墊時，另加焊墊面積的一半（旗標「空洞與焊墊重疊」） |

判定時以「空洞率 ± k × 估計誤差」與規格比較，接近規格者列為需複判。

## 3. 參數

| 參數 | 預設 | 說明 |
|---|---|---|
| `ball_radius_min_px`／`ball_radius_max_px` | 20／120 | **須依產品設定**：只包含要檢測的焊點種類。範圍同時涵蓋不同結構（例如 BGA 錫球與帶焊墊亮瓣的凸塊）時，外形模型會混用 |
| `min_void_diameter_ratio` | 0.08 | 最小空洞直徑（焊點直徑比例） |
| `sigma_k`（進階） | 4.0 | 空洞種子門檻的雜訊倍數 |
| `min_depth`（進階） | 0.07 | 空洞最小相對深度，約對應直徑 11% 的球形空洞 |
| `rim_exclusion`（進階） | 0.10 | 邊緣排除環帶 |
| `max_fit_rms`（進階） | 0.12 | 外形擬合誤差上限，超過視為外形不符而不量測 |
| `method` | rule | 空洞分割方法：規則式／深度學習模型／兩者並用（差異超過 3 個百分點需複判），見 SPEC-007 |
| `model` | （不使用） | 深度學習模型「模型代碼@版本」 |

## 4. 判定規格

| 規格 | 預設 | 說明 |
|---|---|---|
| `void_pct_max` | 25 % | 單顆空洞率上限（IPC-7095 常用的 BGA 錫球第 3 級上限） |
| `largest_void_pct_max` | 不啟用 | 最大單一空洞上限 |
| `total_void_pct_max` | 不啟用 | 總空洞率上限 |
| `max_failed_balls` | 0 | 允許超規焊點數 |
| `max_unmeasured_balls`（進階） | 0 | 允許未量測焊點數；超過時需複判 |
| `confidence_k`（進階） | 2.0 | 判定信心倍數 |

未量測的焊點（外形不符、對比不足、與相鄰焊點重疊、擬合失敗）列入判定，不會被略過；位於影像邊緣的焊點由相鄰影像檢測，不列入。

## 5. 成像品質指標

| 指標 | 警告 | 不合格 | 說明 |
|---|---|---|---|
| `void.measurable_ratio` | < 0.5 | < 0.2 | 可量測焊點比例 |
| `void.contrast` | < 8 | < 5 | 焊點中心吸收量 ÷ 雜訊 |
| `void.min_detectable_pct` | > 5 % | > 15 % | 依雜訊推算的最小可偵測空洞率 |

門檻為初始值，取得實際影像後校正。

## 6. 模組驗證狀態

| 項目 | 內容 |
|---|---|
| 單位 | 模組代碼 + 主版.次版（修訂版只修正錯誤、不改變量測結果，沿用同一核准） |
| 資料 | `module_validations` 資料表（資料庫結構版本 3），只新增；最新一筆為目前狀態 |
| 初始值 | 微凸塊對位 1.1 已有回歸基準與重拍重複性驗證，升級時標示已驗證 |
| 效果 | 分析時由工作佇列帶入已驗證清單；未驗證模組的合格／不合格改為需複判，原因「檢測模組尚未驗證」，紀錄與報告註記 |
| 核准與撤銷 | 「配方管理 > 檢測模組」，工程師以上；核准須填說明（驗證影像集、結果摘要），可填驗證報告編號；記入稽核 `module.validate`／`module.revoke` |
| API | `GET /api/modules/validation`、`POST /api/modules/{module_id}/validation` |
| 工程用命令列 | `analyze` 不檢查驗證狀態 |

## 7. 驗收結果（合成影像，2026-09-23）

合成影像依 Batch2 實測數值：背景吸收量 0.75、焊球對比 0.3、焊墊 +0.08、背景雜訊 0.016、邊緣模糊 1.5 px；截頂球焊球（半徑約 70 px）、球形空洞、偏心焊墊、走線格紋、光子雜訊。

| 項目 | 規劃書標準 | 結果 |
|---|---|---|
| 空洞檢出（直徑 ≥ 焊球 15%） | ≥ 95 % | 193／193（100 %） |
| 無空洞焊球誤報 | ≤ 2 % | 0／115（有／無焊墊各 8 張） |
| 空洞率誤差（空洞與焊墊不重疊） | ≤ 2 個百分點 | 平均 +0.10、95 % 分位 1.66、最大 2.33；空洞貼近邊緣時 95 % 分位 1.83 |
| 成像條件不變性（曝光 ×0.5～×2、吸收量 ×0.6～×1.5） | ≤ 1 個百分點 | 系統性偏移 95 % 分位 0.77～1.14、最大 1.17；同條件重拍 95 % 分位 1.11，偏移與重拍雜訊同一量級 |
| 空洞率 ≥ 25 % 的焊點 | 不可漏判 | 37 顆全部偵測到，沒有任何一顆落入合格（空洞率 + 2 × 估計誤差 ≤ 25） |
| 焊墊干擾 | 焊墊不得判為空洞 | 符合 |
| 效能（6 百萬像素、252 顆，單行程） | ≤ 5 秒 | 3.4 秒（10 % 焊點有空洞）～4.9 秒（60 %） |

### 7.1 實際影像（不誤報確認）

| 影像 | 結果 |
|---|---|
| Batch1（8-bit，10 張，預設半徑範圍） | 2 顆焊點出現 1.4～2.4 % 的小區域，遠低於規格；8-bit 影像判定本就最多需複判 |
| Batch2 1、2、4、8、9 號，半徑範圍設為 BGA 錫球（55～95 px） | 83 顆可量測，0 誤報 |
| Batch2 3、5、6、7 號（畫面以帶焊墊亮瓣的複合凸塊為主） | 複合凸塊多數判為外形不符而不量測；少數可量測的焊點出現 3.6～15.8 % 的誤報。這類影像並非空洞檢測的對象，實際使用時以半徑範圍與檢測區域（5b）排除 |

## 8. 已知限制

| 限制 | 影響與對策 |
|---|---|
| 空洞蓋住焊墊 | 焊墊增加的吸收量抵消空洞，重疊部分無法由影像還原，空洞率偏低。以擴大估計誤差轉為需複判（第 2.1 節）；代價是空洞接近焊墊、空洞率 13～25 % 的焊點較常列為需複判（合成影像中約 9 % 的焊點，實際比例依焊墊與空洞的位置而定） |
| 靠近邊緣的大空洞（> 30 %） | 低估 1～7 個百分點，仍高於 25 % 規格；無法擬合時列為未量測 |
| 半徑範圍涵蓋不同結構 | 外形模型混用，可能誤報或大量不量測；配方須依產品設定半徑範圍 |
| 合成影像與實際空洞的差異 | 形狀、對比、重疊情形可能不同；取得實際影像後以驗證工具（5e）量化，再調整參數與品質門檻 |
| 8-bit 轉存影像 | 可分析，判定最多需複判（平台規則） |

## 9. 平台擴充（本階段新增，其他模組可共用）

| 項目 | 說明 |
|---|---|
| 面積單位 | 量測值鍵以 `_px2` 結尾時，有像素尺寸即自動加上 `_um2` |
| 物件排行表 `finding_table` | 模組宣告物件類別、排序量測值、欄位與筆數；檢閱畫面與報告自動顯示排行表與分布直方圖 |
| 通用摘要 | 模組 `summary` 中的數值欄位以 `summary.<鍵>` 語系顯示，不需另寫畫面 |
| 判定原因的對象 | `代碼:ballN` 顯示為「（焊點 N）」 |
