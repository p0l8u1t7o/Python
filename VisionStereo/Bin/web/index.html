操作說明

    

      

        
滾輪以游標為中心縮放

拖曳頂點調整 polygon ROI

        
拖曳多邊形內部整體位移

        
雙擊邊線在該處插入頂點

        
Alt+點頂點 / 右鍵點頂點刪除該頂點

        
O自動優化 ROI（貼合影像邊緣＋平滑，不會自動儲存）

        
N / V新增多邊形 / 回到選取模式

        
0–9把選取物件改成該類別

        
Delete刪除選取的多邊形

        
← → / A D上一張 / 下一張（有變更會先詢問是否儲存）

        
Ctrl+S / Ctrl+Z儲存 / 復原

        
F / G符合視窗 / 100%
