# Role & Task Definition
You are an expert Full-Stack Computer Vision Engineer. Your task is to design, architect, and build a modular, high-performance web platform similar to Roboflow. The platform provides end-to-end dataset management, intelligent image annotation, data augmentation, and model training workflow.

---

## Technical Stack Architecture (Strict Requirement)

- **Frontend**: React.js (JavaScript/TypeScript), Vite, TailwindCSS, Zustand or React Context for state management.
- **Canvas / Annotation Engine**: Konva.js / React-Konva (High-performance HTML5 Canvas API).
- **Backend Framework**: Python 3.11+ with **Django 5.0+** & **Django REST Framework (DRF)**.
- **Database**: **SQLite** (Using `django.db.models`). Optimize with WAL mode for local concurrency.
- **Asynchronous & Background Tasks**: **Celery + Redis** (or Django Channels for SSE/WebSockets where real-time streaming is needed).
- **AI Core Engines**: PyTorch, Segment Anything 2 (SAM2), Grounding DINO, Ultralytics YOLO.

---

## Core Features & Django Modules to Implement

### 1. Data Ingestion & Dataset Versioning (Django App: `datasets`)
- Models: `Project`, `Dataset`, `DatasetVersion`, `ImageFile`.
- Support uploading image batches (JPG, PNG, WebP) and ZIP packages using DRF `MultiPartParser`.
- Compute Perceptual Hash / SHA256 during upload to detect duplicate images in SQLite.
- Automatic train/val/test dataset splitting logic.
- Dataset Versioning: Freeze datasets and generate JSON/YOLO exports saved as media files.

### 2. High-Performance Annotation Workbench (Django App: `annotations`)
- **Frontend Canvas UI**:
  - Bounding Box (`[x_min, y_min, width, height]`).
  - Polygon Segmentation (Multi-point node insertion, node moving, deletion).
  - Canvas controls: Smooth Zooming (Wheel), Panning (Middle-click/Spacebar), Multi-select.
  - Keyboard shortcuts (1-9 for classes, 'B' for Box, 'P' for Polygon, Delete to remove).
- **Django Smart Auto-Labeling Endpoint**:
  - Integration with SAM2: Receive click point `(x, y)` via DRF endpoint -> run PyTorch inference -> return polygon mask coordinates.
  - Integration with Grounding DINO: Text prompt -> return predicted bounding boxes.

### 3. Preprocessing & Data Augmentation Engine (Django App: `augmentations`)
- Image processing using OpenCV, Pillow, and Albumentations.
- **Preprocessing**: Auto-orient, Resize with Letterbox padding, Grayscale.
- **Augmentations**: Random Flip, Rotation, Brightness/Contrast, Gaussian Blur, Noise, Cutout, Mosaic.
- Celery task pipeline to execute batch dataset augmentation and generate a downloadable `.zip` package.

### 4. Training Pipeline & Model Export (Django App: `trainer`)
- Celery worker task to trigger Ultralytics YOLO training in background.
- Store metric logs (Loss, Precision, Recall, mAP@50) into SQLite.
- Export trained models to ONNX and TorchScript formats.

---

## Technical & Architecture Guidelines for Agent

1. **SQLite Optimization in Django**:
   - Enable SQLite `WAL` mode in Django database setup for better concurrent read/write performance.
   - Store bounding box/polygon coordinates as JSON fields (`models.JSONField`) normalized between `0.0` and `1.0`.
2. **Django Backend Guidelines**:
   - Use DRF Serializers (`ModelSerializer`) for clear input validation and response payloads.
   - Keep AI model loading outside API request loops (e.g., Singleton pattern or Celery worker init) to avoid re-loading SAM2 weights on every HTTP call.
3. **Frontend Canvas Performance**:
   - Separate state layer and rendering layer using React-Konva layers (`<Layer>`). Do not re-render heavy canvas assets unnecessarily.
   - Maintain image dimensions scale ratio between Canvas viewport and original image pixels.
