核心名詞

中文英文／程式定義
流程Flow一張檢測圖（節點＋連線）；每位使用者各自擁有
步驟Node畫布上的一個方塊；一個步驟就是一個工具的實例
工具Tool（ToolTypeDef）工具箱裡的種類（灰階、Blob…）；key 是唯一識別字
連線Edge步驟之間的線：來源輸出埠 → 目標輸入埠
埠Port步驟左側為輸入埠、右側為輸出埠；有型別
分支把手Flow handle型別為 flow 的輸出埠（true／false 等），只能接到步驟的「控制輸入」（菱形）
參數Param步驟的設定值；種類是封閉集合（number、select、roi…）
教導參數 / 參數卡Teach param（Param.teach）／ Teach page需要現場調機的參數（門檻、極性、公差…），工具定義以 teach=True 標記；「參數卡」頁只列全流程的教導參數，依步驟分組，換線調機不必開畫布
公差判定Tolerance judge（tolerance_judge）量測值與「標稱值＋上偏差／＋下偏差」比較，走 pass／fail 分支；判定連同 nominal／upper／lower／unit／spec_source（圖面出處）寫進 run.outputs.tolerances，供 Cpk 與追溯
同心度Concentricity（concentricity）兩圓圓心偏移量（deviation）；GD&T 同心度 = 2×偏移，超過 max_deviation 走 ng 分支
壁厚Wall thickness（wall_thickness）沿剖面找「外緣→內緣」成對邊緣的距離；多條卡尺取 min／max／mean
區域 / ROIRegion在影像上畫的檢測範圍（矩形、旋轉矩形、圓、環、多邊形、線）
標記Overlay工具畫在影像上的結果圖形（框、圓、點、文字…）
執行Run一次完整（或到某步驟為止）的流程執行；結果為 OK／NG／失敗
試執行Preview用未儲存的圖執行、保留所有中間影像；不寫入歷史
執行一次Run once用已儲存的圖執行一次；寫入歷史與統計。UI 已無此按鈕（整合方走 POST /flows/{id}/run、TCP 或整合頁）
連續執行Continuous依間隔不停執行
暫存影像Scratch image只為試執行上傳的影像，不進影像來源庫
影像來源Image source相機／資料夾／合成／API 送圖／擷取端相機的定義
擷取端Capture client（vscapture）裝在相機所在電腦的桌面程式：驅動網路攝影機／Basler／IDS，主動連到伺服端擷取埠（9100）；同一台電腦以共享記憶體、跨電腦以 TCP 無損傳影像
通道Channel擷取端裡的一台相機（名稱、種類、裝置、ROI、參數、傳送設定）；網頁來源以「擷取端＋通道」指定
擷取端相機Capture source（kind=capture）影像來源種類：client／channel／mode／timeout_ms／fresh／encoding
依需求取像 / 連續串流On demand / Stream每次執行向擷取端要一張觸發之後的新影格；或擷取端依 fps 上限持續推最新影格、執行時直接取用
共享記憶體Shared memory（shm）擷取端與伺服端在同一台電腦時的影像通道：擷取端建立區段與槽、FRAME 訊息通知、伺服端 copy 一次後 SLOT_FREE 歸還
資產Asset範本影像、ONNX 模型等檔案
判定JudgeOK／NG 的結論（judge 工具）
具名輸出Output回傳給自動化系統的鍵值（output 工具）
引擎鎖定Engine lock整合方鎖住硬體：其他人只能編輯不能執行
整合方Integrator以 API 金鑰呼叫的自動化系統
重置Reset清除該流程在記憶體內的執行紀錄與統計
範本庫Template library（FlowTemplate）流程範本：內建（builtin:<key>）或自訂（存為範本）；來源 id 以 {SOURCE} 佔位，建立／載入時再選影像來源
範本Template範本庫裡的一筆；「載入範本」以 t{n}_ 前綴改節點 id 避免撞名；範例樣板（demo.BUILTIN_TEMPLATES）都在這裡，配「範例：⋯」樣本來源即可執行
註解Note（畫布便利貼）graph 的裝飾節點（type=note，不參與執行）；工具箱「新增註解」放到畫布中央，選中後在屬性面板改標題／內文、拖角落調大小
批次測試Batch test（/batch、BatchPage、apps/vision/batch）選流程用影像集批量執行並暫存每次逐張結果的調機工作台；含期望標記、洞察、調參重跑、比較、AI 諮詢與調整
影像集Batch set（BatchSet）一組批量測試用的影像＋每張的期望標記（OK／NG）；檔案在 ASSET_DIR/batch/
批次執行Batch run（BatchRun、執行紀錄）用某份 graph 快照跑影像集的一次執行；逐張結果與 summary 暫存，origin＝手動／草稿／自動調參／AI 調整，parent 串起調參前後
資料洞察Insights（batch/insights.py、洞察分頁）命中率、混淆矩陣、未命中影像、出錯節點、建議門檻、輸出分佈、與上一次差異
建議門檻Threshold suggestion（insights.judges[].suggestion）依期望 OK／NG 兩群的判定輸入值找出的較佳門檻，可一鍵套用到調參面板
資料諮詢Consult（POST /agent/consult）針對一次批次執行的資料提問；規則洞察＋LLM 回答，附可套用的參數建議
全域 AI 助手Assistant dock（AssistantDock、POST /agent/chat）右下角常駐的聊天視窗，切換頁面不消失（對話存瀏覽器）；依頁面脈絡分流：使用說明問答、修改流程、資料諮詢、依資料調整
使用說明問答Help answer（agent/help.py、模式「使用說明」）把 docs 章節與工具技能建成檢索索引，依問題找相關段落；LLM 只依片段回答並引用章節，離線時回文件節錄與 /docs/ 連結
助手脈絡Assistant context（useRegisterAssistantContext、lib/assistantContext.ts）頁面登記給全域助手的資訊：kind（流程編輯器／工具頁／批次測試…）、目前 graph、套用回呼、批次執行 id；離開頁面自動清除
工作階段Agent session（AgentSession、/agent/sessions、AI 助手頁「歷史」）一次 AI 助手生成的完整記錄（影像、ROI、需求、流程、判定、評分）；可還原、可當相似影像的參數先驗
參數先驗Prior（memory.priors_from_sessions、候選「沿用過去成功參數」）相似成功案例的現場調機參數，套到新草稿、自動調參候選最前與 LLM 的過去案例段
補充要領Custom skill（AgentSkill、/agent/skills/custom）站點（管理員）或個人對內建 AI 技能的 markdown 補充；站點進 system 段、個人進 user 訊息
代理模式Agentic mode（AgentSettings.mode、/agent/jobs、AgentTimeline）AI 助手以動作（試跑、修改、驗證、提問）逐步完成流程的背景工作，前端顯示步驟時間軸；相對於「單次生成」
步驟時間軸Step timeline（AgentTimeline、job.steps）代理工作的每個動作／回覆／提問／完成記錄，含摘要與耗時；執行中可中斷
候選方案Candidate（synth.candidates、candidates[]）AI 助手規則引擎對同一意圖產出的主要方案＋參數變體；全部試跑後依影像標記打分，勝者正式跑，可在助手頁切換
影像標記Image label（GenerateIn.labels、縮圖右下角 OK／NG）每張上傳影像的期望判定；候選排名與自動調參的依據，ROI 提示「好品／壞品」亦自動成為標記
自動調參Autotune（apps/vision/agent/autotune.py、/agent/autotune、/golden/autotune）資料驅動的座標下降：只動 teach 參數、嚴格變好才採納；入口為 AI 助手生成、批次測試「自動調參」、Golden Set「自動調參」
定位補正三件套Locate wrap（synth.wrap_with_locate；ROI 提示「定位」）範本比對 → 定位補正 → ROI 跟隨；AI 助手在工件位置會變時自動包在流程前面

回歸Regression（POST /regress）以正式模式執行全部案例，與期望值和基準比對：total／match／mismatch／match_rate、混淆矩陣、退步（regressed）／進步（improved）清單；只對 mismatch 的案例保留影像
基準Baseline（GoldenBaseline）某次回歸「存為基準」後每個案例的結果；下次回歸以它算退步／進步與「與基準不同」
退步 / 進步Regressed / Improved基準符合、這次不符 = 退步（was → now）；反之 = 進步。改參數後最該看的清單
