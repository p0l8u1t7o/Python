核心名詞

中文英文／程式定義
流程Flow一張檢測圖（節點＋連線）；每位使用者各自擁有
步驟Node畫布上的一個方塊；一個步驟就是一個工具的實例
工具Tool（ToolTypeDef）工具箱裡的種類（灰階、Blob…）；key 是唯一識別字
連線Edge步驟之間的線：來源輸出埠 → 目標輸入埠
埠Port步驟左側為輸入埠、右側為輸出埠；有型別
分支把手Flow handle型別為 flow 的輸出埠（true／false 等），只能接到步驟的「控制輸入」（菱形）
參數Param步驟的設定值；種類是封閉集合（number、select、roi…）
教導參數 / 參數卡Teach param（Param.teach）／ Teach page需要現場調機的參數（門檻、極性、公差…），工具定義以 teach=True 標記；「參數卡」頁只列全流程的教導參數，依步驟分組，換線調機不必開畫布
公差判定Tolerance judge（tolerance_judge）量測值與「標稱值＋上偏差／＋下偏差」比較，走 pass／fail 分支；判定連同 nominal／upper／lower／unit／spec_source（圖面出處）寫進 run.outputs.tolerances，供 Cpk 與追溯
同心度Concentricity（concentricity）兩圓圓心偏移量（deviation）；GD&T 同心度 = 2×偏移，超過 max_deviation 走 ng 分支
壁厚Wall thickness（wall_thickness）沿剖面找「外緣→內緣」成對邊緣的距離；多條卡尺取 min／max／mean
區域 / ROIRegion在影像上畫的檢測範圍（矩形、旋轉矩形、圓、環、多邊形、線）
標記Overlay工具畫在影像上的結果圖形（框、圓、點、文字…）
執行Run一次完整（或到某步驟為止）的流程執行；結果為 OK／NG／失敗
試跑Preview用未儲存的圖執行、保留所有中間影像；不寫入歷史
執行一次Run once用已儲存的圖執行一次；寫入歷史與統計。UI 已無此按鈕（整合方走 POST /flows/{id}/run、TCP 或整合頁）
連續執行Continuous依間隔不停執行
暫存影像Scratch image只為試跑上傳的影像，不進影像來源庫
影像來源Image source相機／資料夾／合成／API 送圖的定義
資產Asset範本影像、ONNX 模型等檔案
判定JudgeOK／NG 的結論（judge 工具）
具名輸出Output回傳給自動化系統的鍵值（output 工具）
引擎鎖定Engine lock整合方鎖住硬體：其他人只能編輯不能執行
整合方Integrator以 API 金鑰呼叫的自動化系統
重置Reset清除該流程在記憶體內的執行紀錄與統計
範本庫Template library（FlowTemplate）流程範本：內建（builtin:<key>）或自訂（存為範本）；來源 id 以 {SOURCE} 佔位，建立／載入時再選影像來源
範本Template範本庫裡的一筆；「載入範本」以 t{n}_ 前綴改節點 id 避免撞名
批次測試Batch test多張影像（檔案／來源抓 N 張，≤50）用目前的圖各跑一次試跑，看良率與每張判定；影像只保留最近 8 次（KEEP_RUN_IMAGES），被淘汰的顯示「影像已釋放」
統計Statistics（StatsPage）資料庫歷史的 KPI、每小時 OK／NG／失敗、耗時趨勢與執行歷史表；「記憶體即時統計」是引擎內的 FlowStats
整合頁Integration page外部整合方的接口說明與測試工具；「事件監看」連 /api/vision/events
收藏Favorites工具箱裡按星號的工具（localStorage vs.favoriteTools）；「最近使用」已移除
已教導 / 未教導Commissioned（Flow.commissioned）參數卡頁「標記為已教導」後為 true；false 時流程列表／總覽／頂列顯示「未教導」標籤，執行的 RunReport.warnings 帶「未完成現場教導」但不阻擋
配方Recipe（FlowRecipe）同一流程的一組參數覆寫 param_overrides = {node_id: {param: value}}，多料號換線用；執行／試跑／TCP recipe= 可指定（名稱或 id），未指定用綁定配方（is_default）；參數卡頁「編輯對象」選了配方後改動寫進配方而非圖
覆寫Override配方裡的一筆「步驟.參數＝值」；執行時疊到圖上再編譯
Golden SetGolden Set（GoldenCase）有期望值（OK／NG／不限）的影像案例集，存在伺服器（不進影像快取）；來自上傳或批次測試結果
案例Golden caseGolden Set 裡的一張影像＋期望狀態＋（可選）期望輸出＋備註
回歸Regression（POST /regress）用非試跑模式跑全部案例，與期望值和基準比對：total／match／mismatch／match_rate、混淆矩陣、退步（regressed）／進步（improved）清單；只對 mismatch 的案例保留影像
基準Baseline（GoldenBaseline）某次回歸「存為基準」後每個案例的結果；下次回歸以它算退步／進步與「與基準不同」
退步 / 進步Regressed / Improved基準符合、這次不符 = 退步（was → now）；反之 = 進步。改參數後最該看的清單
合格門檻fail_under回歸的 match_rate 低於此值判定為未通過（CLI 退出碼非 0）
站台Station（station_id）每筆 run 帶的站台代號（VISION_STATION_ID）；總覽卡片、統計頁顯示
連線Connection（apps/comm）主動輸出到 Modbus TCP／上位機的連線定義：kind ∈ modbus_tcp／tcp_client／dio_sim／plugin；write_modbus 工具以連線名稱引用（畫布上的「連線」Edge 是另一回事）
寫入 Modbuswrite_modbus輸出類工具：依對映表（mapping：src → address，含 dtype／scale／offset／value）把判定、具名輸出或輸入埠的值寫到連線；失敗預設降級記警告
教導專案DlProject（apps/vision/dl）一種模型（trainer kind）＋類別清單＋樣本集；訓練產物匯出成 kind=model 的資產
自動標記Auto label（Trainer.suggest）對未標記樣本提出建議類別與信心分數（虛線框顯示、批次接受）；接受後記為 auto、人工確認轉 human
模型種類Trainer（apps/vision/dl/base.py）可訓練的模型類型 registry；宣告超參數（Param）、標記模式、支援裝置，實作 train／suggest；外掛可新增
標記編輯器ShapeWorkspace（components/dl）shapes 模式（分割／偵測）的標記工作區：縮圖牆巡檢、polygon/bbox 編輯、自動優化（輪廓貼邊）、快捷鍵；座標 0~1 正規化
大圖檢視ClassifyWorkspace（components/dl）分類教導的大圖工作區：縮圖牆＋原圖檢視器（縮放／1:1）＋類別按鈕標記；與網格檢視切換、共用篩選
工具欄ToolRail（標記編輯器內）標記編輯器畫布左側的大圖示垂直工具欄：選取／多邊形／框／智慧選取／自動優化／刪除／還原，各鈕標示快捷鍵
智慧選取Smart select（apps/vision/dl/sam.py）標記編輯器的 SAM 點擊標記：點一下物件 → 伺服端分割出輪廓 → polygon 掛目前類別；權重預設 mobile_sam.pt 自動下載，需可選安裝 ultralytics
資料集分割Split（DlSample.split）train／val／test／未指定；「自動分割」分層隨機指派，狀態列分割 chip 可單張切換；val 當驗證集、test 不進訓練
資料集版本Dataset version（DlDatasetVersion）凍結當下樣本＋標記＋分割成 zip 存進資產庫（kind=dataset）；shapes=YOLO 樹、classes=類別資料夾＋manifest；可下載、刪除
資料增強Augment（超參數「增強」群組）訓練時擴增樣本：內建模型為翻轉＋亮度擾動（只加訓練集）、yolo_seg 曝露 degrees／fliplr／mosaic；預設關閉
重複偵測Dedupe（DlSample.sha256）上傳／匯入／連抓時以解碼後像素的 SHA256 在同專案內去重，回報 duplicates 張數
DL 實例分割dl_instanceDL 類工具：YOLO-seg 風格 ONNX 推論（letterbox、NMS、mask 合成），輸出每個實例的輪廓／類別／分數；可在深度學習頁教導
外掛Plugin（plugins/、apps/core/plugins.py）繼承 Tool／Grabber／Writer 的 .py 丟進 plugins/ 資料夾即自動掛載；外掛內以 ENABLED／label／description 變數控制掛載與顯示（見 plugins.html）
主題風格Theme（ThemeProvider／UserPref）light／dark／cyber（Temp/Style.md 的 Cyberpunk：霓虹綠、銳角、掃描線只鋪在頁面底與側欄——不覆疊影像區，全走 CSS 變數 tokens）／system；localStorage＋登入者回寫 /auth/prefs、/auth/me 帶回跨裝置套用
