使用者手冊

本手冊依操作順序說明 VisionSequence 的各項功能：從登入、建立流程、調整工具參數，到批次測試、範本、AI 助手、深度學習教導與外部整合。介面內的「說明」頁提供同樣內容的精簡版與工具目錄。

1. 登入與帳號

  • 系統尚無任何使用者時，登入頁會顯示「建立第一個管理員」；建立後即以該帳號登入。
  • 管理員可於「使用者」頁新增帳號、指定角色、停用或重設密碼。三種角色：
    角色做得到做不到
    管理員 admin全部，含帳號、通訊連線與系統設定—
    工程師 engineer建立與修改流程、影像來源、資產、深度學習教導、批次測試、Golden 回歸、調整任何參數帳號、通訊連線、系統設定
    操作員 operator執行檢測、啟停連續模式、換線（切換預設配方）、在參數卡頁調整現場參數、看統計改流程結構、訓練模型、批次測試、影像來源與連線設定
    流程屬於產線而不是個人：任何工程師都看得到、改得動所有流程（流程列上的「擁有者」只記錄建立者），工程師離職不會讓流程變成沒人能維護的孤兒。
  • 影像封存：平台預設不保留執行時的影像（記憶體只留最近幾次，重開就沒了）。要能在客訴時拿出「當時看到什麼」，到流程的統計頁把「保留不良影像」打開——之後每次不良與失敗都會把來源影像與結果影像存到磁碟，統計頁的執行紀錄點一列就看得到，超過保留期或總容量上限會自動清掉（VISION_ARCHIVE_DAYS／VISION_ARCHIVE_MAX_GB；整廠的出貨預設用 VISION_ARCHIVE_DEFAULT）。
  • 現場參數是工具作者標記為「現場教導」的參數（例如二值化的門檻、blob 的最小面積）；操作員在參數卡頁改這些會直接存回流程，改到其他參數或流程結構則會被伺服器擋下。哪些參數是現場參數，看工具頁參數表的「現場教導」欄。
  • 右上角使用者選單可修改密碼與登出。整合方以 API 金鑰存取，不需登入。

2. 影像來源庫與資產庫

  • 影像來源：相機（USB／GigE 外掛）、資料夾（循環讀取）、單一檔案、上傳、合成影像。folder／file 類型可按「瀏覽」開啟伺服器檔案瀏覽器選路徑；USB 類型可「掃描相機」列出可用裝置。表單下方的「測試擷取」會依目前設定擷取一張並顯示尺寸、耗時與縮圖，儲存前即可確認路徑或裝置正確。
  • 資產：範本影像（定位、良品比對）、模型檔（ONNX）、資料集 zip。工具頁可「從目前影像框選建立範本」直接存成資產。
  • 兩者皆可建立群組分類（清單上方晶片篩選、「管理群組」改名或刪除）。範例來源與資產位於「範例」群組。

2-3. 相機在別台電腦：擷取端相機

相機接在產線另一台電腦，或需要 Basler／IDS 的廠牌 SDK 時，不用把相機接到伺服器：在影像來源庫頁首「下載擷取端」，到相機所在的電腦解壓執行 VisionSequenceCapture.exe，「連線」填伺服端位址（埠 9100）與擷取端名稱，「通道」新增相機、開啟並開始取像（可在預覽上圈選 ROI 只傳 ROI、調相機參數並儲存）。回到網頁新增來源選類型「擷取端相機」，下拉選擷取端與通道，取像模式選「依需求取像」（每次執行要一張新影格）或「連續串流」，儲存前「測試擷取」確認。清單狀態欄會顯示擷取端在線／離線、fps 與最近影格；「外部整合」→「擷取端」分頁可看所有已連線的擷取端、開串流與預覽。細節見 擷取端。

3. 建立與編輯流程

還沒選影像來源？編輯器上方會出現黃色橫幅，直接在橫幅的下拉選一個來源（或上傳一張暫存影像）就能試執行；總覽頁每張流程卡也有「執行一次」鈕，不用進編輯器。點選取像步驟時，右側檢視器會顯示目前來源的下拉與預覽縮圖，可直接切換來源。

自己寫 Python？工具箱「邏輯」類有「Python 腳本」：在工具頁的程式碼編輯器寫 def run(ctx)（可用 np、cv2、math），讀 ctx.image／上游值 ctx.inputs／現場參數 ctx.params['p1'..'p3']／區域 ctx.roi()，回傳數值、布林、文字、資料、新影像與標記並決定通過／不良分支；輸出埠固定（value、result、text、data、image）。腳本與引擎同行程受限執行（白名單匯入、逾時中止、輸入影像唯讀），只有管理員能編輯與儲存核准；一般使用者可檢視並執行已核准的腳本，也可在參數卡調整現場參數而不必改程式碼。

  1. 「流程」頁「新增流程」，或「從範本建立」。
  2. 編輯器左欄「新增工具」開啟工具選擇視窗（依類別分群、可搜尋、可收藏），點選即加入畫布中央；「新增註解」放置便利貼。
  3. 連線：由上一步的輸出埠拖曳至下一步的輸入埠；同色（同型別）的埠才能相接。判斷類工具的分支埠接到目標步驟的 _flow 埠即為條件執行。
  4. 右側面板：選取步驟後可改標題、啟用狀態、顏色與參數；「開啟工具頁」進入專屬調參頁。
  5. Ctrl+S 儲存。未儲存的變更會保留為草稿，離開再回來仍在；「執行一次」與「連續執行」使用已儲存的版本。

4. 工具頁與 ROI

  • 版面：左為參數、中為「執行前／執行後」影像、下為參考資訊（直方圖、統計、輸出值）、右為操作按鍵。
  • 參數變更後預設不會自動執行；按「試執行至此步驟」查看結果。開啟「自動套用」則變更後 250 ms 自動執行。
  • 參數修改為暫存狀態：按「儲存」寫回流程；未儲存直接返回編輯器會詢問是否放棄。
  • ROI：有「區域」參數的工具進頁即顯示 ROI；在影像上拖曳繪製矩形／旋轉矩形／圓／橢圓／環（可設起迄角）／多邊形／折線／線段／點，座標為該步驟輸入影像的像素座標。
  • 「上傳暫存影像」只為試執行放一張影像（不進來源庫）；「用上次影像重跑」固定同一張影像調參。

5. 試執行、執行與連續執行

動作使用的版本說明
試執行目前畫布（含未儲存）保留所有中間影像；不寫入執行紀錄。
執行一次已儲存與外部觸發相同的正式執行；寫入執行紀錄與統計。
連續執行已儲存依設定間隔反覆執行；總覽頁可觀看即時影像與結果。

總覽頁左側選擇流程，中央顯示最近一次執行的影像與標記、右側顯示判定與輸出值；無事件時顯示最後一次執行結果。

6. 批次測試與 Golden Set

  1. 側欄「批次測試」（或編輯器頂列「批次測試」）：「新增影像集」上傳影像或從影像來源擷取 N 張（一個影像集最多 200 張）。影像集清單跨流程，同一組影像可用任一流程測試。
  2. 右上「測試流程」＝要用哪個流程測這組影像；選影像集時會自動帶成它建立時的流程，想比較另一個流程就換選單再執行。編輯器有未儲存草稿時可勾「使用編輯器未儲存的草稿」。
  3. 按「以「流程名稱」執行」：背景批量執行、顯示進度、可中斷；每次執行的逐張結果都暫存，執行紀錄可回看（用別的流程測的執行會標出流程名稱）。
  4. 「影像集」分頁為每張影像標記期望 OK／NG，「結果」分頁即顯示命中率與逐張命中；「洞察」分頁列出未命中影像、出錯節點、判定門檻建議、輸出分佈與歷次趨勢，「套用並重新執行」直接產生新的一次執行。
  5. 「調參」分頁修改現場調機參數後「重新執行」，「比較」分頁逐張對照兩次執行；滿意後「寫回流程」「存為配方」或「帶回編輯器」。
  6. 右下角的全域 AI 助手（選定已完成的執行後）：提問（例如「為什麼第 3 張 NG？」）或下達調整指令；調參面板的「自動調參」；結果都成為新的一次執行。
  7. 勾選影像「存入 Golden Set」作為回歸基準；「Golden Set」頁可執行回歸與自動調參，退步案例置頂。詳見批次測試與Golden Set 與匯出。

7. 範本畫廊

18 個內建範本（計數、曝光、圓孔量測、邊線夾角、良品比對、織紋瑕疵、前處理教學、多圓幾何、顏色有無、顏色比對、條碼標籤、定位量測、杯件量測等）皆附合成樣本圖；建立時選擇對應的「範例：⋯」來源即可直接執行。自己的流程可「存為範本」供他人重用。詳見範例樣板。

8. AI 助手

全域 AI 助手：每個頁面右下角都有 AI 助手按鈕，開啟後是常駐的聊天視窗，切換頁面不會消失。直接輸入問題（例如「如何從資料夾建立影像來源？」）會依平台文件回答並附「參考文件」連結；在流程編輯器輸入修改語氣的句子（例如「把 blob 的最小面積改成 40」「停用去雜訊」）會直接修改目前畫布，按「套用到畫布」寫回（可復原）；在批次測試頁選定一次已完成的執行後，可提問資料（「為什麼第 3 張 NG？」）或下達調整指令，結果成為新的一次執行。視窗上方的模式晶片可強制指定「使用說明／修改流程／資料諮詢／依資料調整」。以下是 AI 助手頁（側欄「AI 助手」）從影像生成整條流程的步驟：

  1. 上傳一張或多張影像；在影像上圈選檢測位置，每個 ROI 自動編號（ROI01、ROI02…）並可補充提示。
  2. 以一句話描述需求，例如「應該有 5 個孔」「量直徑 17.5±0.4mm」「ROI01 是好品，ROI02 是壞品，找出差異」。
  3. （選填）點選縮圖右下角的標記，指定該影像應判 OK 或 NG；ROI 提示寫「好品」「壞品」的影像也會自動成為標記。ROI 提示填「定位」可指定位置固定的定位標記，工件位置會變時流程會自動加上定位補正。
  4. 按「生成檢測流程」：助手先確認資訊是否足夠（必要時提問），再生成流程並在每張影像實跑，影像上疊顯檢測標記、縮圖標示 OK／NG。規則引擎會產生數個候選方案並依標記擇優，結果卡可點選切換；有兩張以上標記時會自動調參。
  5. 以回饋語句微調（「誤判過多」「期望數量改為 4」「公差 ±0.2」），滿意後「存成流程」進入編輯器；結果卡的讚／倒讚會影響之後相似影像是否沿用此參數。

「歷史」可檢視過去的工作階段，「還原」會把影像、ROI、需求與標記帶回並在原影像重跑；「AI 技能」除了瀏覽，也可在每個技能下方寫個人（或站點）補充要領，AI 會一併讀取。供應商設定的「工作模式」選「代理模式」後，助手會以動作逐步起草、試執行、修改並驗證流程，畫面顯示步驟時間軸，可隨時中斷或回答助手的提問。

右上「AI 供應商」可選擇離線規則引擎或 Claude／GPT／Gemini 並填入個人 API 金鑰（僅存於伺服器、綁定帳號）；儲存後自動測試連線並顯示結果，「列出可用模型」可查詢金鑰可用的模型名。「AI 技能」可瀏覽助手所遵循的平台規則與工具要領。詳見 AI 助手。

9. 深度學習教導

  1. 建立教導專案並選擇模型種類（分類、語意分割、實例分割）。
  2. 收集樣本：上傳、zip 批次、從來源連續擷取或匯入資料集；重複影像自動略過。
  3. 標記：分類以點選縮圖指定類別；分割以多邊形／矩形標記，可用「智慧選取」點選物件自動描邊；可先「自動標記」再確認。
  4. 分割 train／val／test、凍結資料集版本，按「開始訓練」；完成後模型匯出至資產庫，於流程中以 DL 工具使用。

詳見 深度學習教導。

10. 外部整合與引擎鎖定

  • 「外部整合」頁提供 HTTP／TCP 測試工具、即時事件監看、Modbus 連線與主動輸出設定、回傳格式說明。
  • HTTP：POST /api/vision/flows/{id}/run（可附影像、指定配方）；TCP：RUN <id> 一行指令；事件：SSE 串流。
  • 整合方可以 API 金鑰鎖定引擎：鎖定期間使用者僅能編輯流程，所有連續執行停止。

詳見 自動化整合與 Modbus 輸出。

擷取端分頁：下載擷取端程式（版本、大小、SHA-256）、伺服端擷取埠是否監聽、設定步驟；已連線的擷取端與通道（尺寸、模式、fps、最近影格、使用中的來源），可直接開關串流與預覽。見 擷取端。

11. 設定與個人偏好

  • 介面語言（繁體中文／簡體中文／English）與主題風格（淺色／深色／Cyberpunk／跟隨系統）儲存於個人帳號，跨裝置一致。
  • 管理員可於設定頁管理 API 金鑰與引擎鎖定。

12. 常見問題

狀況處理方式
試執行顯示「影像已不在快取中」重新上傳暫存影像或執行一次流程取得新影像。
找圓／找線回報找不到確認 ROI 蓋住邊緣（找圓用環形 ROI、卡尺 ROI 橫跨兩條邊），降低邊緣門檻或調整極性。
AI 供應商測試連線失敗依視窗顯示的原因處理：金鑰無效、模型已下架（依提示改名）、供應商過載（稍後再試或換模型）、逾時（檢查網路）。
執行回報「引擎已鎖定」整合方鎖定中；等待解鎖或由管理員解除。
連續執行卡在「佇列已滿」降低執行間隔或檢查流程耗時；可於效能報告了解各工具成本。

相機在另一台電腦，或需要 Basler／IDS 的 SDK，怎麼接？

用擷取端：影像來源庫「下載擷取端」→ 在相機電腦執行並連到伺服端 → 網頁新增「擷取端相機」來源選擷取端與通道。同一台電腦會自動走共享記憶體，跨電腦走 TCP 無損傳送；清單顯示「擷取端離線」代表擷取端程式沒連上。詳見 擷取端。

擷取端相機執行時逾時？

先在擷取端確認通道狀態是「取像中」且預覽有畫面；觸發模式的相機要有觸發訊號；曝光時間長或跨網路時把來源的「逾時（毫秒）」放大；「要求新影格」取消可直接用擷取端手上的最新影格。
