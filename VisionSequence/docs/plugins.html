自訂工具

  1. 任意 Python 模組（例如 plugins/my_tools.py，專案根目錄下 plugins/__init__.py 建一個空檔）：
from apps.vision.tools.base import Param, Port, Result, Tool, ToolContext, ToolError, flow_out, register
from apps.vision.tools.roi import crop, region_overlay

class DarkRatioTool(Tool):
    key = "dark_ratio"                 # 全域唯一
    label = "暗區比例"
    description = "ROI 內灰階低於門檻的像素比例。"
    category = "detect"                # source|preprocess|locate|measure|detect|dl|logic|output
    icon = "Moon"                      # lucide-react 圖示名
    params = [
        Param("roi", "區域", kind="roi", shapes=["rect", "rotated_rect", "circle"]),
        Param("threshold", "門檻", kind="number", default=80, minimum=0, maximum=255),
        Param("max_ratio", "允許比例", kind="number", default=0.1, minimum=0, maximum=1, step=0.01),
    ]
    inputs = [Port("image", "影像", "image"), Port("roi", "區域（動態）", "region", required=False)]
    outputs = [Port("ratio", "比例", "number"), flow_out("pass", "通過", "ok"), flow_out("fail", "不良", "critical")]

    def execute(self, ctx: ToolContext) -> Result:
        image = ctx.require_image()
        if image.ndim == 3:
            import cv2; image = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
        region = ctx.roi()
        c = crop(image, region, upright=True)
        if c.image.size == 0:
            raise ToolError("ROI 在影像外")
        mask = c.mask if c.mask is not None else None
        pixels = c.image[mask > 0] if mask is not None else c.image
        ratio = float((pixels < ctx.number("threshold", 80)).mean()) if pixels.size else 0.0
        ok = ratio <= ctx.number("max_ratio", 0.1)
        overlays = [region_overlay(region, label=f"dark {ratio*100:.1f}%")] if region else []
        return Result(outputs={"ratio": ratio}, branch="pass" if ok else "fail",
                      status="ok" if ok else "ng", overlays=overlays, message=f"暗區 {ratio*100:.1f}%")

register(DarkRatioTool())
  1. .env：VISION_TOOL_PLUGINS=plugins.my_tools（逗號分隔多個）。重啟後端，前端調色盤自動出現。

規則

  • Param.kind 只能用 PARAM_KINDS；Port.type 只能用 PORT_TYPES（apps/vision/tools/base.py）。
  • 可預期失敗 raise ToolError("…")（節點 error、run failed）；「沒找到」回 status="ng" 或走分支，不要 raise。
  • overlays 座標一律是該節點輸入影像的全圖座標；旋轉 ROI 用 crop(upright=True) 後以 Crop.to_full() 換回。
  • 不要在工具內 sleep 或碰資料庫；需要檔案用 ctx.asset_path(id)；需要相機用 ctx.grab(source_id)。
  • 重工具（DL 推論）把 session 快取在模組層並加鎖；heavy = True 讓前端提示。

自訂影像來源（例如 GigE / 廠牌 SDK）

# plugins/gige.py
import numpy as np
from apps.vision.sources.grabbers import Grabber

class GigEGrabber(Grabber):
    kind = "gige"
    def __init__(self, config, **kw):
        super().__init__(config, **kw)
        self.cam = open_camera(config.get("serial"))   # 廠牌 SDK
        self.cam.set_exposure(float(config.get("exposure_us", 5000)))
    def grab(self) -> np.ndarray | None:
        frame = self.cam.snap(timeout_ms=1000)
        if frame is None:
            self.last_error = "timeout"; return None
        self.frames += 1
        return frame                      # BGR 或灰階 uint8
    def close(self): self.cam.close()
    def info(self): return {**super().info(), "serial": self.config.get("serial")}

.env：VISION_SOURCE_PLUGINS=gige=plugins.gige:GigEGrabber。前端「影像來源」頁 kind 下拉會出現 gige，config 以 JSON 填。

同一個來源物件會被快取重用（設定變更才重開）；grab() 可能被多個流程的執行緒同時呼叫，內部要自己加鎖（self._lock）。
