擴充外掛：資料夾丟檔即掛載

三種擴充點都走同一套物件繼承：繼承對應的基底類別，把 .py 檔丟進專案根目錄的 plugins/ 資料夾，重啟後端就會自動偵測掛載，不用改 .env、不用改前端。

擴充什麼繼承掛載後出現在出貨範例
工具（畫布節點）apps.vision.tools.base.Tool編輯器調色盤（分類依 category）plugins/example_dark_ratio.py
影像來源apps.vision.sources.grabbers.Grabber「影像來源」頁 kind 下拉本頁 §4（GigE）
整合輸出（連線）apps.comm.writers.Writer「連線」頁 kind 下拉plugins/example_csv_writer.py

本頁目錄

1. 掛載規則與外掛內變數

  • 啟動時掃描 plugins/*.py（照檔名排序；底線開頭 _xxx.py 跳過），資料夾位置可用 VISION_PLUGIN_DIR 覆寫（預設專案根目錄 plugins/）。
  • 每個檔案 import 後，自動偵測該檔案自己定義的 Tool／Grabber／Writer 子類別並註冊；一個檔案可放多個類別、三類混放。
  • key／kind 與內建或先載入的外掛重複時不覆蓋，記 log 略過；單一檔案載入失敗只記 log，不影響其他外掛與平台啟動。
  • 載入器在 apps/core/plugins.py；掛載結果看後端啟動 log（「外掛 xxx.py 掛載：tool:dark_ratio…」）。

外掛檔內可用變數控制顯示與掛載（慣例放檔案最上面，現場要改名／停用不必動邏輯）：

DISPLAY_NAME = "暗區比例"       # 顯示名稱（label）
DESCRIPTION  = "說明文字…"      # 說明（description）
ENABLED      = True             # False = 整個檔案不掛載

class MyTool(Tool):
    label = DISPLAY_NAME
    description = DESCRIPTION
    enabled = ENABLED           # 類別層開關：False 只停用這個類別，同檔其他類別照常
變數層級作用
ENABLED = False模組（檔案最上層）整個檔案不掛載
enabled = False類別屬性只停用該類別
label／description類別屬性顯示名稱與說明（工具顯示在調色盤；Grabber／Writer 顯示在 kind 下拉）
fields類別屬性（Grabber／Writer）config 欄位名稱提示，設定頁顯示用，例如 ["path"]

2. 自訂工具（範例一：plugins/example_dark_ratio.py）

DISPLAY_NAME = "暗區比例（範例外掛）"
DESCRIPTION = "ROI 內灰階低於門檻的像素比例，超過允許比例走「不良」分支。"
ENABLED = True

import cv2
from apps.vision.tools.base import Param, Port, Result, Tool, ToolContext, ToolError, flow_out
from apps.vision.tools.roi import crop, region_overlay

class DarkRatioTool(Tool):
    key = "dark_ratio"                 # 全域唯一；圖 JSON 記這個
    label = DISPLAY_NAME
    description = DESCRIPTION
    enabled = ENABLED
    category = "detect"                # source|preprocess|locate|measure|detect|dl|logic|output
    icon = "Moon"                      # lucide-react 圖示名
    params = [
        Param("roi", "區域", kind="roi", shapes=["rect", "rotated_rect", "circle", "polygon"]),
        Param("threshold", "門檻", kind="number", default=80, minimum=0, maximum=255, teach=True),
        Param("max_ratio", "允許比例", kind="number", default=0.1, minimum=0, maximum=1, step=0.01, teach=True),
    ]
    inputs = [Port("image", "影像", "image"), Port("roi", "區域（動態）", "region", required=False)]
    outputs = [Port("ratio", "比例", "number"), flow_out("pass", "通過", "ok"), flow_out("fail", "不良", "critical")]

    def execute(self, ctx: ToolContext) -> Result:
        image = ctx.require_image()
        if image.ndim == 3:
            image = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
        region = ctx.roi()
        c = crop(image, region, upright=True)
        if c.image.size == 0:
            raise ToolError("ROI 在影像外")
        pixels = c.image[c.mask > 0] if c.mask is not None else c.image
        ratio = float((pixels < ctx.number("threshold", 80)).mean()) if pixels.size else 0.0
        ok = ratio <= ctx.number("max_ratio", 0.1)
        overlays = [region_overlay(region, label=f"dark {ratio*100:.1f}%")] if region else []
        return Result(outputs={"ratio": ratio}, branch="pass" if ok else "fail",
                      status="ok" if ok else "ng", overlays=overlays, message=f"暗區 {ratio*100:.1f}%")

不用寫任何 register()——放進資料夾就好。重啟後端，前端調色盤「檢測／識別」分類會出現「暗區比例（範例外掛）」。

3. 自訂整合輸出（範例二：plugins/example_csv_writer.py）

整合輸出（Modbus 輸出的「連線」）同樣用繼承擴充：繼承 Writer，只覆寫 _open／_write／_read／_close；lock、逾時、失敗重連一次、計數統計都在基底的 write()／read()。出貨範例把寫入值附加到 CSV 檔，沒有任何硬體也能驗完整條「流程 → 寫入 Modbus 工具 → 連線」路徑：

DISPLAY_NAME = "CSV 紀錄（範例外掛）"
DESCRIPTION = "把每次寫入的值附加到 CSV 檔（time, address, value）。"
ENABLED = True

import csv, os, time
from apps.comm.writers import CommError, Writer
from apps.core.errors import ValidationError

class CsvLogWriter(Writer):
    kind = "csv_log"                   # Connection.kind 記這個
    label = DISPLAY_NAME
    description = DESCRIPTION
    enabled = ENABLED
    fields = ["path"]                  # 設定頁 config 欄位提示

    def __init__(self, config, **kw):
        super().__init__(config, **kw)
        self.path = str(config.get("path") or "")
        if not self.path:
            raise ValidationError("csv_log 需要 path", code="comm_config")

    def _write(self, values):          # {address: value} → {"written": n}
        ...                            # 完整實作見 plugins/example_csv_writer.py

掛載後「連線」頁 kind 下拉出現「CSV 紀錄（範例外掛）」；建一條連線（config 填 {"path": "D:/logs/results.csv"}），流程末端放「寫入 Modbus」工具、connection 填連線名稱即可。OPC UA、廠牌 SDK 等照同樣模式：連不上 raise CommError，工具層會依 on_error 降級（預設不讓 run 失敗）。

4. 自訂影像來源（例如 GigE / 廠牌 SDK）

# plugins/gige.py — 丟進 plugins/ 即掛載
DISPLAY_NAME = "GigE 相機"
ENABLED = True

import numpy as np
from apps.vision.sources.grabbers import Grabber

class GigEGrabber(Grabber):
    kind = "gige"
    label = DISPLAY_NAME
    description = "廠牌 SDK 封裝；config: serial, exposure_us"
    fields = ["serial", "exposure_us"]
    enabled = ENABLED

    def __init__(self, config, **kw):
        super().__init__(config, **kw)
        self.cam = open_camera(config.get("serial"))   # 廠牌 SDK
        self.cam.set_exposure(float(config.get("exposure_us", 5000)))
    def grab(self) -> np.ndarray | None:
        frame = self.cam.snap(timeout_ms=1000)
        if frame is None:
            self.last_error = "timeout"; return None
        self.frames += 1
        return frame                      # BGR 或灰階 uint8
    def close(self): self.cam.close()
    def info(self): return {**super().info(), "serial": self.config.get("serial")}

掛載後「影像來源」頁 kind 下拉出現該來源，config 以 JSON 填。同一個來源物件會被快取重用（設定變更才重開）；grab() 可能被多個流程的執行緒同時呼叫，內部要自己加鎖（self._lock）。

5. 工具撰寫規則

  • Param.kind 只能用 PARAM_KINDS；Port.type 只能用 PORT_TYPES（apps/vision/tools/base.py）。
  • 可預期失敗 raise ToolError("…")（節點 error、run failed）；「沒找到」回 status="ng" 或走分支，不要 raise。
  • overlays 座標一律是該節點輸入影像的全圖座標；旋轉 ROI 用 crop(upright=True) 後以 Crop.to_full() 換回。
  • 不要在工具內 sleep 或碰資料庫；需要檔案用 ctx.asset_path(id)；需要相機用 ctx.grab(source_id)。
  • 重工具（DL 推論）把 session 快取在模組層並加鎖；heavy = True 讓前端提示。
  • 現場要調的參數標 teach=True（參數卡頁只列這些）。

6. 進階：.env 手動掛載

不放 plugins/ 資料夾（例如外掛裝成獨立套件）時，仍可用 .env 指定模組路徑：

VISION_PLUGIN_DIR=D:/site-plugins                     # 換掉資料夾位置（仍是自動偵測）
VISION_TOOL_PLUGINS=mypkg.my_tools                    # import 該模組；模組內自行呼叫 register()
VISION_SOURCE_PLUGINS=gige=mypkg.gige:GigEGrabber     # kind=module:Class
VISION_COMM_PLUGINS=opcua=mypkg.opcua:OpcUaWriter     # kind=module:Class

另外「影像來源」與「連線」都保留 kind=plugin：建立時在 config 填 "class": "mypkg.mod:Class" 直接指定類別路徑。
