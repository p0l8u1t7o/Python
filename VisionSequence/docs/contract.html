graph JSON

{
  "nodes": [{"id": "blob-1", "type": "blob", "label": "找孔", "description": "", "enabled": true,
             "continue_on_error": false, "color": "", "params": {...}, "position": {"x": 0, "y": 0}}],
  "edges": [{"id": "e1", "source": "gray-1", "source_handle": "image", "target": "blob-1", "target_handle": "image"}]
}
  • source_handle = 來源節點輸出埠 key；target_handle = 目標輸入埠 key，或 "_flow"（控制輸入）。
  • 輸出埠 type: "flow" 的把手（例如 if_number 的 true/false）只能接到 _flow。
  • type: "note" 是註解，不執行，不能被連入。

ROI region dict（Param kind=roi 的值）

{"shape":"rect","x","y","w","h"} | {"shape":"rotated_rect","cx","cy","w","h","angle"} |
{"shape":"circle","cx","cy","r"} | {"shape":"annulus","cx","cy","r_inner","r_outer"} |
{"shape":"polygon","points":[[x,y],...]} | {"shape":"line","x1","y1","x2","y2"}

座標為該節點輸入影像的像素座標（原點左上）。

Overlay dict（Result.overlays；畫在該節點輸入影像座標）

kind: rect(x,y,w,h,angle?) / circle(cx,cy,r) / annulus / polygon(points) / polyline(points) / line(x1,y1,x2,y2) / point(x,y) / points(points) / text(x,y,text) / contours(contours=[[[x,y],...]]).

共同欄位：color "#rrggbb"、label、width、dash、fill。

RunReport（POST run / preview 回傳、SSE run_finished 的 run）

{id, flow_id, flow_version, trigger, status: ok|ng|failed, started_at, finished_at, duration_ms, error,
 outputs: {...具名輸出},
 nodes: {node_id: {status: ok|ng|error|skipped, duration_ms, message, branch, outputs: {port: value}, overlays: [...], overlay_on, detail, logs}}}

影像輸出的值為 {"ref": "runid:node:port" | null, "width", "height", "channels"}；GET /api/vision/images/{ref}?max=1024&fmt=jpeg|png。

preview 模式（POST /flows/{id}/preview body {graph, context?, reuse_image_ref?}）保留所有中間影像，且 detail._input_ref 指向該節點輸入影像的 ref。

試跑進階（工具頁用）

  • POST /flows/{id}/preview body：until_node（只跑到該步驟與其祖先）、analysis: true（回 analysis: {input:{ref,histogram,stats}, output:{port,ref,histogram,stats}, series:{"blobs.area":{count,min,max,mean,values}}}）。
  • POST /flows/{id}/scratch-image（multipart image）→ {ref,width,height,name}：暫存影像，不進來源庫；之後 preview 帶 reuse_image_ref。
  • DELETE /flows/{id}/recent：重置記憶體內執行紀錄與統計；SSE 事件 cleared。

Param.kind 補充

  • range：單一數值，以滑桿＋數字框呈現（用 minimum/maximum/step）；不是兩個數字。
