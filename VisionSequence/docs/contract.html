graph JSON

{
  "nodes": [{"id": "blob-1", "type": "blob", "label": "找孔", "description": "", "enabled": true,
             "continue_on_error": false, "color": "", "params": {...}, "position": {"x": 0, "y": 0}}],
  "edges": [{"id": "e1", "source": "gray-1", "source_handle": "image", "target": "blob-1", "target_handle": "image"}]
}
  • source_handle = 來源節點輸出埠 key；target_handle = 目標輸入埠 key，或 "_flow"（控制輸入）。
  • 輸出埠 type: "flow" 的把手（例如 if_number 的 true/false）只能接到 _flow。
  • type: "note" 是註解，不執行，不能被連入。

ROI region dict（Param kind=roi 的值）

{"shape":"rect","x","y","w","h"} | {"shape":"rotated_rect","cx","cy","w","h","angle"} |
{"shape":"circle","cx","cy","r"} | {"shape":"annulus","cx","cy","r_inner","r_outer"} |
{"shape":"polygon","points":[[x,y],...]} | {"shape":"line","x1","y1","x2","y2"}

座標為該節點輸入影像的像素座標（原點左上）。

Overlay dict（Result.overlays；畫在該節點輸入影像座標）

kind: rect(x,y,w,h,angle?) / circle(cx,cy,r) / annulus / polygon(points) / polyline(points) / line(x1,y1,x2,y2) / point(x,y) / points(points) / text(x,y,text) / contours(contours=[[[x,y],...]]).

共同欄位：color "#rrggbb"、label、width、dash、fill。

身分與錯誤形狀

  • 權杖：Authorization: Bearer <token>（所有端點，含事件串流與影像）；瀏覽器不能帶標頭的地方用 ?token=。整合方金鑰：X-API-Key 或 ?api_key=。
  • 錯誤一律是 {"error": {"code": "…", "message": "…", "details": {…}}}——包含 401（unauthenticated）。
  • 事件串流 /api/vision/events、/api/vision/flows/{id}/stream 是 text/event-stream，不在 OpenAPI schema 內；位址在 GET /vision/integration/info。

RunReport（POST run / preview 回傳、SSE run_finished 的 run）

{id, flow_id, flow_version, trigger, status: ok|ng|failed, started_at, finished_at, duration_ms, error,
 outputs: {...具名輸出},
 nodes: {node_id: {status: ok|ng|error|skipped, duration_ms, message, branch, outputs: {port: value}, overlays: [...], overlay_on, detail, logs}}}

影像輸出的值為 {"ref": "runid:node:port" | null, "width", "height", "channels"}；GET /api/vision/images/{ref}?max=1024&fmt=jpeg|png。

preview 模式（POST /flows/{id}/preview body {graph, context?, reuse_image_ref?}）保留所有中間影像，且 detail._input_ref 指向該節點輸入影像的 ref。

試執行進階（工具頁用）

  • POST /flows/{id}/preview body：until_node（只跑到該步驟與其祖先）、analysis: true（回 analysis: {input:{ref,histogram,stats}, output:{port,ref,histogram,stats}, series:{"blobs.area":{count,min,max,mean,values}}}）。
  • POST /flows/{id}/scratch-image（multipart image）→ {ref,width,height,name}：暫存影像，不進來源庫；之後 preview 帶 reuse_image_ref。
  • DELETE /flows/{id}/recent：重置記憶體內執行紀錄與統計；SSE 事件 cleared。

Param.kind 補充

  • range：單一數值，以滑桿＋數字框呈現（用 minimum/maximum/step）；不是兩個數字。
  • code：程式碼字串（accept＝語言，目前只有 python，用於 python_script 工具）；前端以等寬、有行號的編輯器呈現，非管理員唯讀。只有管理員儲存過的程式碼會被核准執行（apps/vision/scripts.py；POST/PATCH /flows 與匯入時登記 sha256，一般使用者送未核准的腳本回 403 script_not_approved；配方不能覆寫 code；試執行的 context 由伺服器依身分加 _script_admin，外部送來的 _ 開頭鍵一律丟棄）。
  • 每個工具的 outputs 目錄末尾有隱含埠 {"key":"_overlays","type":"list","implicit":true}（該節點的標記），可接 draw_result 的 overlays。
  • 影像位深：image 埠可承載 uint8（預設）、uint16（16-bit 灰階／RGB U64）、float32（SGL 浮點）。工具以 Tool.accepts 宣告支援的位深；宣告外的位深由 ToolContext.image() 自動正規化成 u8（u16 右移 8、浮點 min-max；不動輸入陣列）。顯式轉換用 convert_depth 工具。詳見 檢測功能設計。
  • 每個工具的 outputs 另有隱含影像直通埠 {"key":"_image","type":"image","implicit":true}：原影像原樣往下傳（標記只是 metadata、不畫進影像，下游檢測不受影響）；沒有任何 image 輸入的工具（邏輯類）inputs 也補 _image 直通輸入，影像可經過任何工具。停用的節點照樣直通。直通 ref 只在「被接走」時出現在 run report（它不是「執行後」結果；檢視器與工具頁分析一律忽略 _image）。

前後端解耦部署

前端是純靜態 SPA，只透過 frontend/src/lib/api.ts（HTTP）與 lib/flowStream.ts（SSE）和後端往來；所有路徑以 BASE_URL 為基底，頁面程式碼不直接呼叫 fetch。

部署方式前端後端
同站（預設）npm run build 產物由 whitenoise 隨 API 行程服務，BASE_URL=/apimanage.py serve
開發Vite dev server，/api 代理到 8000同上
獨立部署build 時設 VITE_API_BASE_URL=https://vision.example.com/api，放任何靜態主機／CDN.env 設 CORS_ALLOWED_ORIGINS=https://console.example.com
  • 認證：登入 token 走 Authorization: Bearer；整合方 API 金鑰走 X-API-Key。影像／SSE 這類 <img>／EventSource 無法帶 header 的請求以 ?token=／?api_key= 附帶（withKey()）。
  • 各頁面為獨立 lazy chunk（App.tsx），首屏只載入外框與當前頁；共用大套件（React、React Flow、圖表）另切 chunk 以利快取。
  • 回應格式與錯誤碼見本頁上方各節；新增端點時只要維持這些 schema，前端不需改動即可相容。
