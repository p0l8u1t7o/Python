# 五站 3D 視窗與產品追隨操作

更新：2026-09-27。適用於 AutomaticAcid-BaseTitration、MilitaryGradePC、PCB-CopperAssembly、RobotArmPressSSD、shutter assembly。

## 相機畫面

- 拖曳相機標題列即可移動視窗，包含主畫布以外的位置。鍵盤聚焦標題列後也可用方向鍵移動。
- **⛶**：放大／縮小，相機視野比例保持不變。
- **↗**：開啟獨立相機視窗。原面板會暫時隱藏，影像、ROI 標記、取像狀態與時間都由主頁送出，沒有第二條動畫時間軸。
- **×**：隱藏面板；上方 **▣** 圖示可恢復顯示。獨立開窗時，按 **▣** 可放回主頁。
- 獨立視窗中的「回到主頁」按鈕或關閉視窗，都會恢復原面板。「標記」按鈕與主頁共用檢測標記開關。
- 主頁播放、暫停、重播、拖拉時間軸、前後步驟與相機來源切換，均會更新同一相機畫面。主頁重新載入／切換機種時會關閉獨立視窗，之後可重新開啟。

請保留主頁開啟；獨立視窗不會自行播放。瀏覽器可能將新視窗顯示成分頁，也可能封鎖彈出視窗；遇到封鎖時，頁面會提示允許後重試。主頁若被瀏覽器背景節流，子視窗也只能接收主頁實際產生的幀。

## 收合資訊

主畫布上緣保留 **◧／◨** 圖示，可分別切換左／右資訊。收合後主畫布與時間軸會使用釋出的空間。只有滴定站原本有左側樣品表，其餘站提供右側資訊圖示。

滴定站在較窄的螢幕上預設收起左表，仍可用圖示開啟。相機面板、資訊面板彼此獨立；隱藏資訊不會停止動畫。

## 手機與窄螢幕

視窗寬度不超過 900 px，或觸控裝置高度不超過 500 px 時，五個展示頁使用精簡介面：

- 預設收合左右資訊、相機與詳細控制，主動畫使用完整寬度。
- **☰** 開啟製程與視角選單，選擇站點或視角後收合。
- 下方保留播放、時間軸、時間；**⚙** 展開速度、重播與步驟等設定。
- 資訊與電盤以可捲動面板顯示；相機仍可拖曳與開獨立視窗。一次只展開一組面板，避免重疊遮擋。
- 橫向且高度不超過 500 px 時，工具圖示合併到頂列，增加動畫高度。
- 切換手機／桌面寬度時會保存並恢復桌面側欄與相機顯示狀態，動畫沿用同一時間軸。

已用瀏覽器原生尺寸 iframe 驗證五站的 320×568、390×780、844×390 與 1280×800 排版及部分面板操作；這不是實機手機／Safari 測試。量測紀錄見 [mobile-layout-checks.json](../review/mobile-layout-checks.json)。

## 產品焦點

點選 **◎** 啟用近距離追隨，再次點選即解除。啟用後仍可旋轉與縮放主視角；鏡頭隨產品的世界座標平移，保留使用者調整的觀察方向。解除後停留在當下視角，不再追隨產品。選擇一般預設視角也會解除這個焦點模式。

| 專案 | 新焦點模式追隨對象 |
|---|---|
| 酸鹼滴定 | 正在夾持／處理的瓶杯；等待分析時改看滴定中的杯子 |
| 軍規電腦 | 主流程中的電腦，包含輸送、升降與翻面位置 |
| PCB 銅箔組裝 | 本節拍由 S1 送至 S2、接受散熱片放置的基板 |
| SSD 接頭壓合 | 載盤與產品，包含進板、頂升、壓合及出板 |
| 快門組裝 | 本體，包含料盤取放、治具組裝與成品下料 |

為減少近距離遮擋，焦點模式僅在主視角渲染時暫時隱藏外罩群組，解除後恢復原設定；治具、工具與零件保持可見。原有「跟隨手臂」、液面／銀腳特寫等專用視角保留各自功能。PCB 原動畫為五站並行的穩態單節拍，焦點沿原模型中的同一基板移動，不虛構一片產品完整跑過五站的新排程。

滴定站新增的相機面板是**虛擬製程觀察相機**，不是新增實體檢測設備。其餘各站使用原有檢測相機與原有來源切換規則；相機標記仍為模擬結果。

## 實作與驗證

共用來源為 `tools/viewer-workspace.js` 與 `tools/viewer-workspace.css`。修改後執行：

```powershell
node tools/sync-viewer-workspace.mjs
```

各網站保留獨立的 JS／CSS 副本，可單站部署。相機使用同一 WebGL renderer 的離屏目標，再把影像送至面板／獨立視窗；這避免拖出主畫布時遭裁切，也保留同幀的機構狀態。HDR 影像經 ACES 曝光與 sRGB 轉換後顯示，ROI 使用同一鏡頭投影。

已在本機瀏覽器操作五站，驗證拖曳、隱藏還原、面板收合、開窗返回、跳站／倒轉同步與焦點解除。紀錄見 [viewer-workspace-checks.json](../review/viewer-workspace-checks.json)，畫面位於各站 `review/viewer-workspace.png`。本次修改呈現與操作介面，未更動機構運動排程。
