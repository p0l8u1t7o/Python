# 相機視覺檢測標記

四案均新增可開關的螢幕座標標記，使用當前相機矩陣投影 3D 目標。標記隨取像、物件運動、視角和畫面大小更新，不修改物件材質或相機光學視野。角框、中心十字和引線標籤會避讓；畫面外及相機後方目標不顯示，邊界不完整目標顯示待完整取像。

所有結果均為 **SIM 模擬**，來自模型與排程，不是實拍影像辨識。青色表示預覽／追蹤，綠色表示模擬符合條件或目標存在，紅色表示模擬 NG，黃色表示待取像。軍規電腦的 ROI 不代表已完成瑕疵判定；滴定體積不是影像測量，pH 也不由相機判斷。

| 專案／相機 | 標記內容 |
| --- | --- |
| SSD 全局 | USB 編號、接頭定位框 |
| SSD 手臂 | 銀腳區、間隙線、模型間隙 mm、配方公差與 OK／NG |
| 銅片供料 A／B | 銅片中心、正反面、可取／翻面與方向角 |
| 銅片仰視 A／B | 本次飛越吸嘴、ΔX／ΔZ mm、θ 補償角；離開取像時間即清除 |
| 銅片下視 A／B | 工具孔 F1～F4 基準點定位 |
| 基板 S1 | 視野內孔號、孔位定位框 |
| 基板 S3 | 視野內銅片／孔位框、模擬放置偏差 mm 與公差判定 |
| 軍規手臂 | 當前取像的接口、護蓋、門扣、封印、Docking、法規、SN／警語、螺絲 ROI；OCR 標示待接入 |
| 滴定近看視角 | 杯／瓶編號、液面輪廓、模型體積 mL、空杯狀態；這是觀察視角，未宣稱新增實體工業相機 |

## 驗證

在 `RobotArmPressSSD` 執行：

```powershell
node --import ../core/tools/register.mjs tools/verify-vision.mjs
```

118 項跨專案檢查通過：投影／縮放／裁切、SSD 配方 NG 門檻、所有銅片相機來源、取像狀態與倒回清除、軍規檢查目標、12 杯液面位置。既有 28 次 SSD 取像、50 次軍規取像／20 個接口、兩個銅片配方流程及 286 項滴定渲染狀態檢查亦通過。瀏覽器已檢視四案畫面及標記開關、縮放。
