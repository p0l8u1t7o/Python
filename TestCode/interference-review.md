# 四站干涉修正紀錄

日期：2026-09-26。以下為網頁模型中的幾何／取像干涉，單位 mm。

| 專案 | 找到的問題 | 修正 |
|---|---|---|
| AutomaticAcid-BaseTitration | 噴洗嘴與電極圓柱及固定環相交 | 噴洗嘴移至電極側方，固定環間最小淨空 4.20；同步修正噴洗液流起點 |
| AutomaticAcid-BaseTitration | 移液模組吸頭、廢液及落料口穿過實心桌板；吸頭架未開孔 | 桌面建立三個真正貫穿孔，移除封口黑片及實心漏斗底座；吸頭架建立 12 個通道，保留底部承托 |
| MilitaryGradePC | 接口殼／接點突出至閉合護蓋內部 | 接口與背板內縮，兩種 SKU 共 16 個門位最小淨空 0.25；開蓋取像仍可看到接口 |
| RobotArmPressSSD | 彈簧內徑小於導桿；整排彈簧隨壓墊平移後穿入座體 | 增加內徑，固定上端座，只讓下端隨壓墊縮短；驗證完整 0–3 mm 行程 |
| PCB-CopperAssembly | 吸嘴主軸及旋轉馬達穿過未開孔支架 | 頭座與支架建立實際通孔，保留吸嘴及馬達旋轉空間 |
| PCB-CopperAssembly | 兩頭交會時，懸伸支架和下視相機互撞；先前約 26.8 s／15.6 s 可重現 | 縮短支架前緣，相機移至側邊；以實際鏡頭偏移重算基準點拍攝路徑 |
| PCB-CopperAssembly | 固定供料相機位於移載頭行程；抬高後橫樑會遮住早期曝光 | 相機抬至 1460、支柱移至 x=±620；曝光改到頭進入放置區後，驗證盤面中心／四角的視線 |
| PCB-CopperAssembly | S1／S3 掃描架與 S2 橫樑重疊，S3 回原點也進入相鄰行程 | 內側支柱外移、橫樑抬高、相機用細支架下懸；S3 改向外側回原點 |

## 驗證

四個專案各新增 `tools/verify-clearance.mjs`。在各專案目錄執行：

```powershell
node --no-warnings --experimental-loader ./tools/three-loader.mjs tools/verify-clearance.mjs
```

- 銅箔：長圓孔 26,969、圓孔 14,734 個時間樣本（每 2 ms），檢查兩個移載頭、橫樑、供料相機、固定結構與移動掃描頭；另檢查通孔、基準點光軸和供料曝光遮擋。滑軌支承接觸為明確允許的接觸。
- SSD：36 組彈簧／導桿及座體檢查，涵蓋 0、0.5、1.5、3 mm 壓縮；既有 8 種動作組合及 28 個相機取像位置通過。
- 軍規電腦：16 個閉合門位檢查；既有兩種 SKU、50 個鏡頭位置與 20 個接口遮擋檢查通過。
- 滴定：探頭／杯壁／槳葉掃掠、桌面孔及吸頭架通道；既有 9,449 項動作與 286 項渲染狀態檢查通過。

銅箔修正後循環為長圓孔約 53.94 s、圓孔約 29.47 s。這些結果涵蓋上述模型與檢查範圍；取樣及包圍盒檢查不是連續碰撞證明，也未包含實機公差、線纜全行程及全機自碰撞驗證。
