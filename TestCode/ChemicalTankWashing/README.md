# 200L 化學桶自動清洗線：3D 規劃動畫

依 `docs/` 的場地圖（紅框倉儲區）、手繪動線與 200L 閉口 HDPE 桶照片規劃。洗桶區 12.56 × 15.52 m、樓高 4.5 m，倉儲約 200 桶，用 AGV 搬運，清洗手臂用 FANUC。Three.js 依賴放在 `web/vendor`，可以離線執行。

已拍板：倉儲用**穿梭車密集架**；殘液為**酸鹼水溶液**（不需防爆，手臂加防護衣）；**線上自動開蓋**；棧板上料用**龍門加翻轉夾爪**。

## 流程

| 站 | 動作 | 動畫節拍 |
|---|---|---|
| S1 倉儲／AGV | AGV 由車道前位叉出棧板（4 桶）→ 放上棧板站；穿梭車把後方棧板補到前位；空棧板回疊空棧板道 | 約 45 s／棧板 |
| S2 龍門上料 | 雙弧形 PU 爪夾桶 → 抬升 → 先平移出棧板範圍 → 邊移邊翻 90° → 放上 V 形輥（桶頂朝西、桶底朝東） | 約 20 s／桶 |
| S3 貼標讀碼 | 印字貼標頭由南側推出貼標 → 旋轉輥把標籤轉到正上方 → 相機讀 QR、檢查位置 | 約 7 s／桶 |
| S4 90° 翻桶 | L 形搖籃以桶底下緣為軸翻正（桶口朝上），轉往南向立放輸送 | 約 6 s＋復歸 |
| S5 自動開蓋 | 頂視相機定位桶塞 → 旋轉台把 2" 轉北、3/4" 轉南 → 兩支伺服鎖付軸反轉拆蓋 → 桶蓋丟入收集桶 | 約 25 s／桶 |
| S6 手臂清洗 | R-2000iC/165F 取桶 → 送入沖洗站 → 噴槍伸入 2" 桶口噴洗 → 退出 → 搖晃 → 翻 190° 倒入集液漏斗；共 3 道 → 倒置滴乾 → 放上出料輸送 | **約 82 s／桶（瓶頸）** |
| S7 廢液回收 | 逆流沖洗：第 1 道用 TK-R 回收水，第 2、3 道用清水；第 1、2 道經 P-2 送 TK-W 廢液槽，第 3 道回收到 TK-R | 每道 20 L |

整線約 44 桶／h，200 桶約 4.5 h。動畫走完一個棧板（4 桶）共 467 s；同一時間多站並行，交接時刻依站位占用推算（流水線阻塞）。

## 場地檢核（網頁右側「空間檢核」，16 項全數通過）

- **倉儲容量**：5 道 × 4 深 × 3 層 = 60 位，扣掉空棧板道 4 位剩 56 位，可放 224 桶（需求 200 桶）。柱子前方的道位無法進出，所以分成西 3 道、東 2 道；東側兩道往西靠，讓 AGV 能原地迴轉。
- **樓高**：第 3 層貨頂 3,935 mm，與 4.5 m 樓高之間有 565 mm 灑水頭淨空；層間淨空 100 mm。
- **AGV 走道**：寬 3.6 m，載棧板時迴轉半徑 1,662 mm。四個迴轉點與牆、柱、龍門的最小淨距是 88–138 mm，相當緊，要現場確認。
- **門與通道**：D3、更衣室門的開門範圍內沒有設備；更衣室到產線的人員通道寬 1.13 m。
- **清洗手臂**：最遠取放點距基座 1,458 mm，型錄伸展 2,655 mm。圍籬內含取桶 → 沖洗站的東南迴轉路徑，以 DCS 限制動作範圍。

與手繪圖不同的地方：
- **裝填區**：手繪圖在東南角，這裡改到西南角。倉儲前要留 3.6 m 的 AGV 走道，產線因此整體往南移，東南角又要給清洗手臂迴轉。
- **廢液槽**：放在清洗區圍籬外的西南側。原因是手臂的迴轉路徑會經過東南角。

## 啟動

```powershell
python serve.py            # http://127.0.0.1:8775/
python serve.py --no-open
```

或雙擊 `run.bat`。ES module 需要 HTTP，不能用 `file://` 開。

## 操作

- 上方 S1–S7 跳到各站第一個事件並切換視角；下方下拉選單列出 35 個流程事件，可以前後步跳轉，時間軸可以拖曳，播放速度 0.25–8×。
- 視角：全景、俯視配置、倉儲 AGV、龍門上料、貼標讀碼、翻桶、開蓋、清洗手臂、沖洗站、廢液回收、跟隨 #1。
- 右側面板：設備狀態（每台目前動作）、4 桶追蹤（貼標／讀碼、桶蓋、沖洗次數、桶內水量）、水槽液位、空間檢核。
- 顯示選項：尺寸＋AGV 迴轉圈＋手臂伸展範圍、圍籬與光柵、標籤、天花板高度、透視桶身（看桶內水量）、相機子畫面（讀碼與桶塞定位，影像與結果皆為模擬）。
- 網址參數：`?pause&t=150&view=booth`、`?dims`、`?cam=x,y,z,tx,ty,tz`。主控台可用 `window.sim.seekTo(秒)`、`setView(名稱)`、`play()`、`pause()`。

| 沖洗站 | PP 隔間 1.3 × 1.37 × 2.6 m、氣缸伸縮旋轉噴頭、集液漏斗與集液槽、排氣接廠務洗滌塔 |

## 待確認

1. **現場丈量**：場地圖局部比例不一致，以下都是依整體比例推估，誤差約 ±300 mm：
   - 柱位：約 X 8.3 m、Z 5.2 m，800 見方；
   - 紅框深度：約 5.1–5.6 m，貨架前緣取 5.4 m；
   - 更衣室凸出與各門位置。

   另外要確認 4.5 m 是樓高還是梁下淨高，以及灑水頭與燈具的位置。
2. **桶規格**：桶徑與桶高、兩個桶塞的位置（是否 180° 對稱）與螺紋規格、最大殘液量（影響夾爪與手臂負載）。
3. **化學品清單**：酸、鹼殘液混在同一個廢液槽可能反應。是否要依標籤桶號分流到兩個廢液槽？
4. **處理量目標**：手臂約 44 桶／h。若需求更高，要加第二個沖洗站或第二台手臂。
5. **穿梭車數量**：每道每層一台，或由 AGV 換道共用。這兩種做法的成本差距大。
6. **其他**：標籤內容與 MES／WMS 介面；廢液委外清運或廠內中和；桶蓋是否回用；洗完的桶是否在下一站封蓋。

## 驗證

需要 Node.js 22 以上，不用安裝 npm 套件：

```powershell
node --no-warnings --experimental-loader ./tools/three-loader.mjs tools/verify.mjs
```

以 0.05 s 取樣整段動畫，檢查以下項目：
- 空間檢核；
- 手臂追蹤誤差、關節限位與關節速度；
- 手臂連桿與夾持中的桶，對沖洗站、輸送、開蓋站立柱、圍籬的干涉；
- 桶與桶是否重疊；
- AGV 車身與載物，對牆、柱、貨架、龍門柱的干涉；
- 交接瞬間是否跳動；
- 倒序取樣的一致性。

最近一次結果在 [review/verification.json](review/verification.json)：全數通過。手臂追蹤誤差 ≤ 0.05 mm；關節速度最高為額定的 83%（J6 搖晃）；手臂與沖洗站、輸送的最小淨距 172 mm；倒序取樣差異 0。

這是有限取樣檢查，不是連續碰撞證明。手臂以線段加半徑近似，桶以 62 個表面點近似，沒有涵蓋線纜、軟管，以及 AGV 與人員的動態干涉。

瀏覽器檢查需要先執行 `python serve.py --no-open`：

```powershell
node tools/browser-check.mjs
```

用本機 Chrome 無頭模式開網頁，收集主控台錯誤、每 2 秒抽查狀態，並截下 12 張站別畫面到 `review/screens/`。
