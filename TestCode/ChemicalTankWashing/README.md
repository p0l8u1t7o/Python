# 200L 化學桶自動清洗線：3D 規劃動畫

依 `docs/` 的場地圖（紅框倉儲區）、手繪動線與 200L 閉口 HDPE 桶照片規劃。洗桶區 12.56 × 15.52 m、樓高 4.5 m，倉儲約 200 桶，用 AGV 搬運，清洗手臂用 FANUC。Three.js 依賴放在 `web/vendor`，可以離線執行。

已拍板：
- **倉儲**：穿梭車密集架。
- **殘液**：酸鹼水溶液，不需防爆，手臂加防護衣。
- **開蓋**：線上自動開蓋。
- **上料**：棧板上料用龍門加翻轉夾爪。
- **入庫**：散桶入庫，依手繪圖箭頭由倉儲西牆南段進入，需要上棧板。
- **清洗**：雙孔進水；末道倒液後以負壓抽乾殘水。
- **動線**：翻桶後直線送到裝填區。

## 流程

| 站 | 動作 | 動畫節拍 |
|---|---|---|
| S0 散桶入庫 | 作業員用台車把散桶從西牆捲門推入 → 懸臂吊夾住桶頂 L 環，放上入庫站空棧板（先放遠側兩格）→ AGV 由走道以 R2600 弧線轉入，取走滿棧板入架 | 約 15 s／桶 |
| S1 倉儲／AGV | AGV 叉出車道前位棧板（4 桶）→ 放上棧板站；穿梭車把後方棧板補到前位。卸完的空棧板直接送到入庫站重複使用 | 約 45 s／棧板 |
| S2 龍門上料 | 雙弧形 PU 爪夾桶 → 抬升 → 平移出棧板範圍 → 邊移邊翻 90° → 放上水平沙漏形（V 槽）滾輪；桶頂朝西 | 約 20 s／桶 |
| S3 貼標讀碼 | 貼標頭由南側推出貼標 → 旋轉輥把標籤轉到正上方 → 相機讀 QR | 約 7 s／桶 |
| S4 90° 翻桶 | L 形搖籃以桶底下緣為軸翻正，接著一路往南直送 | 約 6 s＋復歸 |
| S5 自動開蓋 | 頂視相機定位 → 旋轉台把 2" 轉北、3/4" 轉南 → 伺服鎖付軸反轉拆蓋 | 約 25 s／桶 |
| S6 手臂清洗 | R-2000iC/165F 從「取桶位」取下 → 經過渡點送入沖洗站 → 每道：2" 旋轉噴頭與 3/4" 直噴頭同時進水 → 搖晃 → 翻 190° 倒液（3/4" 在上方當通氣口）；共 3 道 → **末道後桶身微傾 3°，2" 噴槍長行程伸到桶底，以真空泵負壓抽乾殘水** → 放回同一條線的「放回位」，再往南直送裝填區 | **約 119 s／桶（瓶頸）** |
| S7 廢液回收 | 逆流沖洗：第 1 道用 TK-R 回收水，第 2、3 道用清水；第 1、2 道經 P-2 送 TK-W，第 3 道與抽出的殘水回收到 TK-R | 每道 20 L |

整線約 30 桶／h，200 桶約 6.6 h。動畫走完「散桶入庫 4 桶＋一個棧板 4 桶清洗」共 619 s，各站並行，交接時刻依站位占用推算。

**手臂節拍的組成**：
- **進水**：雙孔進水每道 13.3 s（2" 60 L/min＋3/4" 30 L/min）；只用 2" 單孔要 20 s，雙孔每桶省約 20 s。
- **倒液**：3/4" 通氣，每道約 3.5 s；不通氣約 7 s。
- **負壓抽乾**：每桶多約 16 s。

想再縮短，可以加第二個沖洗站，讓手臂在兩站之間交替；或把每道水量依實測殘液濃度減少。

## 手臂負重（R-2000iC/165F）

| 項目 | 數值 | 容許 |
|---|---:|---:|
| 總重（夾爪估 60 kg＋桶 8.5＋殘液 2＋水 20） | 91 kg | 165 kg |
| J5 手腕力矩（重心距 J5 約 0.76 m） | 471 N·m | 921 |
| J6 手腕力矩（桶內水偏離 J6 軸） | 84 N·m | 461 |
| J5 慣量 | 31 kg·m² | 78.4 |

以 J5 力矩反推，桶內最多可裝約 80 L 水，目前每道 20 L 有充分餘裕。網頁右側「手臂負載」會隨桶內水量即時顯示。容許值取型錄等級概略值，夾爪重量是估計值，採購前需以 FANUC 負載曲線核對。

## 場地檢核（網頁右側「空間檢核」，20 項全數通過）

- **倉儲容量**：5 道 × 3 層，柱子前方的道位無法進出，所以分成西 3 道、東 2 道。最西一道只做 3 深，讓出 AGV 轉入入庫站的空間。合計 57 位，扣空棧板道 4 位後剩 53 位，可放 **212 桶**。
- **樓高**：第 3 層貨頂 3,935 mm，與 4.5 m 樓高之間有 565 mm 灑水頭淨空。
- **AGV**：走道 3.6 m，載棧板時迴轉半徑 1,662 mm。迴轉點最小淨距 71–105 mm，緊，要現場確認。入庫弧線 R2600：載棧板與空叉時，車身與牆、貨架、懸臂吊的淨距都 ≥ 100 mm。
- **入庫門**：西牆捲門寬 1.7 m。人員通道與 AGV 入庫段共用，設區域警示並讓 AGV 減速。
- **清洗手臂**：最遠取放點距基座 2,158 mm（型錄伸展 2,655 mm），以 DCS 限制在圍籬內。

## 操作

- 上方 S0–S7 跳到各站並切換視角；下拉選單列出所有流程事件，時間軸可以拖曳，播放速度 0.25–8×。
- 視角：全景、俯視配置、散桶入庫、倉儲 AGV、龍門上料、貼標讀碼、翻桶、開蓋、清洗手臂、沖洗站、廢液回收、跟隨 #1。
- 右側面板：設備狀態、桶槽追蹤（含殘水是否抽乾）、手臂負載、水槽液位、空間檢核。
- 顯示選項：尺寸、AGV 迴轉圈與入庫弧線、手臂伸展範圍、圍籬、標籤、天花板、透視桶身、相機子畫面。
- 網址參數：`?pause&t=230&view=booth`、`?dims`。主控台可用 `window.sim.seekTo(秒)`、`setView(名稱)`。
- 畫面閃爍已處理：
  - 改用對數深度緩衝，近裁切面 100 mm；
  - 地面分區固定繪製順序；
  - AGV 警示燈改成亮度脈動，不再切換材質。

## 待確認

1. **現場丈量**：柱、門、更衣室位置與紅框深度（誤差約 ±300 mm）；樓高或梁下淨高；西牆外側是否能開 1.7 m 捲門。
2. **桶規格與殘液**：桶塞位置與螺紋、最大殘液量；抽乾後的殘水標準（模擬設定 < 50 mL）。
3. **酸鹼分流**：酸、鹼廢液是否分兩個廢液槽（可依桶號自動切換）。
4. **處理量目標**：每小時 30 桶是否足夠。不夠的話，可以加第二個沖洗站。
5. **穿梭車數量策略**：每道每層一台，或由 AGV 換道共用。
6. **其他**：標籤格式與 MES 介面、廢液處理方式、桶蓋是否回用。

## 驗證

```powershell
node --no-warnings --experimental-loader ./tools/three-loader.mjs tools/verify.mjs
```

以 0.05 s 取樣整段動畫，檢查：
- 空間檢核；
- 手臂追蹤誤差、關節限位與速度；
- 手臂連桿與夾持中的桶，對沖洗站、輸送、開蓋站、圍籬的干涉；
- 手臂碰到未夾持的桶；
- 8 個桶互不重疊；
- AGV 車身與載物，對牆、柱、貨架、龍門、懸臂吊的干涉（含入庫弧線）；
- 交接瞬間是否跳動；
- 倒序取樣的一致性。

結果在 [review/verification.json](review/verification.json)：全數通過。手臂追蹤誤差 ≤ 0.05 mm；關節速度最高為額定的 83%；手臂與設備最小淨距 172 mm。

這是有限取樣檢查，不是連續碰撞證明。

瀏覽器檢查（先執行 `python serve.py --no-open`）：`node tools/browser-check.mjs`。用本機 Chrome 無頭模式收集主控台錯誤，並截下 17 張站別畫面到 `review/screens/`。
