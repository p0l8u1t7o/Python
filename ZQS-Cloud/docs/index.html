ZQS Cloud 文件

表後儲能能源管理平台 — 從設備通訊到電費受益的完整說明。

第一次接觸建議順序：本機執行 → 專有名詞解釋 → 技術原理 → 系統邏輯總覽；要做設備端請直接看 裝置通訊協定；要在別的專案重用流程引擎請看 工作流程引擎設計手冊。

本機執行
一行指令啟動整個堆疊；三種模式；模擬器；疑難排解。
客戶展示指南
客戶展示的準備、15 分鐘流程、受益數字怎麼算、自我檢查。
專有名詞解釋
MQTT、Sparkplug、需量、契約容量、SOC…每個詞在本系統裡對應到什麼。
技術原理
資料流、Sparkplug 生死流程、能源平衡、電費與受益、策略、警報、引擎、即時性。
系統邏輯總覽
系統目前實際的行為規則：分類、能量平衡、命令閘門、宣告、成本、session。
裝置通訊協定（Sparkplug B）
設備端實作 Sparkplug B 所需的一切：主題、payload、流程、命令回覆。
設備分類設計
設備分類與能力旗標的設計提案。
設備測試工具
對設備端實作做驗收測試的工具。
LabVIEW 整合
以 LabVIEW 做設備端時的整合指引。
工作流程引擎設計手冊
畫布式控制流程引擎：物件類別、演算法、前端做法、踩過的坑、移植步驟。
程式碼導覽
目錄結構、行程、每個 app 負責什麼、如何擴充。
發行說明
每一版驗證範圍、修正、已知限制。
