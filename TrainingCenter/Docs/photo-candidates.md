# 元件照片候選 URL

涵蓋 137 個不重複元件（DB 共 175 筆，跨設備重複的已合併）。每個元件分兩區：

**A. Commons 候選圖** — 來自 Wikimedia Commons，已濾為 CC / Public Domain 的 JPEG/PNG，URL 可直接下載。
信心度由關鍵字比對推算（高／中／低），目前 高 74、中 32、低 31。
**低信心的請不要直接用**，多半抓錯東西（例：安全光柵抓到 Keyence 數位顯微鏡、三色警示燈抓到 Turner 的燈塔油畫）。

**B. 找圖連結** — 原廠產品頁與圖片搜尋。工業元件的正確圖幾乎都在這裡。
這些是**有版權**的商業圖片，是否使用請自行判斷（內部教育訓練通常可，對外公開發布需取得授權）。

## 使用注意

- Commons 下載走 `commons.wikimedia.org/w/thumb.php`（寬 1024）；`upload.wikimedia.org` 對非瀏覽器 UA 一律 403。
- CC BY / CC BY-SA 要求標示**作者 + 授權條款 + 來源**，請保留每張圖的「授權 / 來源頁」
  （`Component.photo_credit` 與 `photo_source_url` 就是放這個用的）。
- 縮圖預覽：用瀏覽器開 `Docs/photo-candidates.html`。
- 機器可讀版本：`Docs/photo-candidates.json`。
