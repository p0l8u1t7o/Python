INTAKE

來料了，這到底是什麼元件？

倉庫送來一箱東西，包裝上只有一組型號。這一章教你怎麼從外觀判斷大類、從哪裡找型號、以及該核對哪幾個欄位才敢簽收。「看起來很像」不是驗收標準。

找不到銘牌時的順序

  • 先看本體：雷雕或印字通常在側面、尾端、或線材出口附近。氣缸看缸身、滑軌看側面、馬達看背面。
  • 再看包裝：外箱與內袋的標籤通常最完整，拆封前先拍照留存，很多人拆完就找不到型號了。
  • 還是沒有：量關鍵尺寸（缸徑、行程、軸徑、螺紋規格、線長）＋拍照，拿去問採購或工程，不要自己猜著上機。
  • 混料最危險：同型號不同行程、不同線長、左右手件、NPN 與 PNP，外觀幾乎一樣但完全不能互換。
🔍 外觀快速判別：先選最接近的長相，再看要核對哪些欄位

⚠ 驗收與入庫的規矩

  1. 沒對過 BOM 型號不簽收。型號差一個字尾，可能就是不同行程或不同輸出型式。
  2. 靜電包裝袋（防靜電銀袋）不要提前拆。PLC 模組、驅動器、相機、感測放大器都怕靜電，要上機前才拆並且戴靜電環。
  3. 精密件不落地、不疊放。滑軌、螺桿、荷重元、力覺感測器、鏡頭要平放在原包裝內。
  4. 有壽命的品項先看日期：電池、O 型環、吸盤、氣管、氫氣感測器都有保存或校期限制。
  5. 異常品立刻隔離掛紅單，不要暫放在良品區「等一下再處理」。混進去之後就找不出來了。
  6. 入庫要貼公司內部料號標籤，並拍一張照補進教材的 photos/ 資料夾。
CHAIN

一個動作，走過哪些元件？

新人最該先記住的不是零件名字，是這條鏈路。任何一個「機台不動」的問題，都是沿著這條線往回查。

用這條鏈路排查「機台不動」

  • 感測器有沒有亮？ 沒亮 → 物件沒到位、感測面髒、線鬆、24V 沒到。
  • PLC 輸入點有沒有 ON？ 感測器亮但輸入沒 ON → 線接錯點、NPN/PNP 接法錯。
  • PLC 輸出點有沒有 ON？ 沒 ON → 是程式條件沒成立，不是硬體壞。回去看互鎖條件。
  • 輸出 ON 但沒動？ 看驅動器 / 電磁閥有沒有得電、有沒有跳警報、氣壓夠不夠。
  • 都正常還是不動？ 才輪到懷疑機構卡死、耦合鬆脫、皮帶打滑。
PART 01

機構系統

負責「把力傳出去、把位置定準」。機構決定了機台精度的上限——電控和軟體只能維持精度，不能創造精度。

兩種最常見的驅動方式

  • 螺桿滑台（伺服）：可以停在任意位置、速度可調、可讀實際座標。用在需要精度或多點定位的軸。
  • 氣壓缸：只有伸出／縮回兩個位置，便宜、力量大、速度靠節流閥調。用在夾持、頂升、擋停這種二元動作。
  • 怎麼知道氣缸到位？ 靠缸身上的磁簧開關（Reed Switch）。程式不會「假設」它到了，一定要等到位訊號。
  • 常見錯誤：氣缸沒到位訊號就往下走，結果撞機。這是新人改程式最容易犯的錯。

⚠ 機構作業安全

  1. 手進到機構範圍前，先斷電 + 洩氣壓 + 掛牌上鎖（LOTO）。只按急停不算安全，殘壓還在。
  2. Z 軸、垂直軸在斷電後可能因自重掉落，維修前先加安全支撐塊。
  3. 手動盤動螺桿前，確認伺服已 Servo OFF，否則會頂著馬達。
  4. 不要用手指去確認吸盤有沒有真空——用真空壓力表看。
PART 02

氣路系統

自動化機台一半以上的動作靠壓縮空氣。氣路的邏輯跟電路很像：有一個「電源」（空壓機）、一路降壓分配、由「開關」（電磁閥）決定通往哪裡。差別在於它會漏、會有水、而且斷電之後殘壓還在。

氣路的四個判斷點

  • 壓力夠不夠？ 看調壓閥上的壓力表，不是聽聲音。動作慢、力量不足、到不了位，先量壓力。
  • 有沒有水？ 濾水杯積水要排。水進到閥和氣缸會造成動作卡頓與內部鏽蝕。
  • 是電的問題還是氣的問題？ 按電磁閥上的手動測試鈕：會動＝氣路正常，問題在電；不會動＝氣路或機構有問題。
  • 有沒有漏？ 停機時應該安靜。持續有嘶嘶聲就是漏，用肥皂水找。漏氣是最大的隱形電費。

⚠ 氣路作業安全

  1. 先洩壓再拆管。帶壓下拔快速接頭，氣管會像鞭子一樣甩出來。
  2. 不可以用壓縮空氣吹身體或衣服，也不可以對著人吹。高壓空氣可能造成皮下氣腫。
  3. 氣管切口要平整，插到底再輕拉確認。沒插到底會在運轉中彈開。
  4. 拆下的氣管不要隨手丟在地上踩，被壓扁的管子會造成間歇性動作異常，非常難查。
  5. 維修垂直氣缸前要確認上方沒有掛載重物，洩壓瞬間會掉下來。
PART 03

電控系統

負責「供電、下命令、收訊號、保安全」。打開電控箱，由上到下通常就是：電源 → 保護 → 控制 → 驅動 → 端子 這個順序。

看盤面的順序

  • 先看有沒有電：主開關 ON？DC 電源綠燈亮？24V 沒了，全部感測器都會「壞掉」。
  • 再看安全迴路：安全繼電器紅燈代表急停／門／光柵有一項沒復歸，此時所有動力輸出都被切掉，程式再對也不會動。
  • 然後看 PLC I/O 燈：輸入燈=外面訊號進來了；輸出燈=PLC 已經下命令了。這兩排燈能解決一半的問題。
  • 最後看驅動器七段顯示：有代碼就查手冊，別亂重開機把證據洗掉。
  • 接地不是裝飾：屏蔽線沒接地，編碼器會亂跳、影像會有雜訊。

⚠ 電控作業安全

  1. 盤內量測一律單手操作，另一隻手不要碰機殼。
  2. 伺服驅動器斷電後電容仍有殘壓，等指示燈熄滅再動（通常 5 分鐘以上）。
  3. 新人不得單獨進行帶電作業，必須有資深人員在場。
  4. 拔插編碼器線、通訊線前一定要先斷電，熱插拔會燒模組。
  5. 改任何安全迴路（急停、門鎖、光柵）都要經主管確認，不得短接了事。
PART 04

軟體系統

負責「決定順序、記錄結果、跟人和其他系統對話」。設備的軟體不是一支程式，而是分層的：底層保安全與即時性，上層管資料與介面。

看懂順序程式的三個重點

  • 狀態先於步驟：機台先決定自己在哪個狀態（待機／回原點／自動／警報），才輪到跑步驟。狀態不對，步驟不會執行。
  • 每一步都要有結束條件：不是「輸出 ON 之後等 1 秒」，而是「等到位訊號 ON」，並且要有 timeout。用時間當條件是不良習慣。
  • 參數和邏輯要分開：動作順序是設計時決定的，速度／座標／延遲是現場調的。分開存，換機種只要換參數。
  • 異常要有代碼：ALARM_1204 這種編號能直接對到排除手冊，比「錯誤發生」有用一百倍。
PART 05

輸送帶模組

輸送帶不只是「會動的帶子」。它是一個由驅動、承載、導引、定位、偵測五個部分組成的模組，而整條線的節拍與稼動率，通常卡在定位站而不是輸送速度。

看輸送線先看這幾件事

  • 順序不能顛倒：一定是擋停 → 頂升 → 作業 → 降下 → 放行。頂升還沒降下就放行，會把定位銷或載具刮壞。
  • 皮帶跑偏調張力，不是換皮帶。左右張力不均或滾筒不平行才是原因，換新的還是會偏。
  • 累積式與非累積式：累積式允許載具在線上排隊互相頂住（滾筒空轉），一般皮帶線不行，塞車會刮傷產品。
  • 載具要有身分：靠 RFID 或條碼，資料才跟得上實體。用「第幾個」來記位置，一旦有人手動拿走一個就全亂了。
  • 夾點是最常見的傷害來源：滾筒與皮帶交界、鏈條與齒輪處都要有護罩，運轉中不可以伸手撥料。
PART 06

機械手臂系統

手臂是「可程式的機構」。它把原本要用一堆氣缸和滑台才能做到的動作，濃縮成一組可以隨時改點位的軸。代價是：它的動作範圍很大，撞到人和撞到機構的風險也更大。

新人碰手臂前要先懂的四件事

  • 座標系有很多套：關節座標、世界座標、工具座標、工件座標。搞錯座標系按方向鍵，手臂會往你意想不到的方向跑。
  • TCP 設錯，點位全錯：換了夾爪一定要重新設定工具中心點與負載重量，否則軌跡與速度都會偏。
  • 示教用低速：教點位時速度限制在 T1 模式（一般 250 mm/s 以下），而且人要站在可以隨時退開的位置。
  • 手臂沒有「安全的直覺」：它會照著點位走，就算路上有東西也一樣。改點位前要先在空跑模式確認軌跡。

選型的直覺

  • 六軸：姿態要變、要斜著進去、要繞過障礙 → 用六軸。彈性最大、速度與剛性較低。
  • SCARA：從上往下取放、鎖付、點膠 → 用 SCARA。同樣節拍下比六軸快也便宜。
  • Delta：輕薄小件高速分揀（配視覺追蹤輸送帶）→ 用 Delta。負載很小。
  • 協作手臂：需要人機共處、不方便架圍籬的站別。速度慢，且仍需做風險評估，不是「一定安全」。

⚠ 機械手臂作業安全

  1. 進入手臂工作範圍前，一律斷電或轉到手動模式並持有 Enable 開關，圍籬門要確實連鎖。
  2. 示教時不要站在手臂與牆壁／機構之間，永遠替自己留一條退路。
  3. 自動啟動前先確認：沒有人在範圍內、程式指標在起始步、手臂已在待機點位。
  4. 手臂斷電後可能因重力下墜，維修前要先支撐或使用剎車釋放的正確程序。
  5. 改過的點位要記錄並備份。手臂程式是財產，掉了就要重教一整天。
PART 07

AOI 檢測機專屬元件

AOI 機台在通用骨架上多了一套光學系統。影像沒拍好，後面再厲害的演算法都救不回來——所以光源和鏡頭比軟體先決定。

新人最需要建立的觀念

  • 先調光，再調參數：缺陷跟背景要有明顯明暗差。光打對了，門檻值幾乎不用細調。
  • 不要用手機拍螢幕當證據：抓到誤判時，把原始影像存下來，連同當時的參數與治具位置一起回報。
  • 過殺 vs 漏檢：漏檢（NG 判成 OK）流到客戶端是重大事故；過殺只是成本。設定門檻時兩者要分開統計。
  • 校正板不是裝飾品：換鏡頭、動到 Z 軸高度、換治具，都要重新做像素對毫米的校正。
  • 鏡頭不要用手擦：吹球 → 拭鏡紙 → 專用清潔液，順序不能顛倒。
PART 08

氫燃料電池發電平台

這台跟一般機台最大的差別：它處理的是可燃氣體與直流高電壓。所有元件都要用「洩漏會怎樣、失效會怎樣」的角度來認識。

進場前一定要知道的事

  • 氫氣無色無味，聞不到不代表沒漏。以偵測器和肥皂水為準，不要靠感覺。
  • 氫氣比空氣輕，會往上累積，所以偵測器裝天花板、通風口也在上方。
  • 爆炸範圍很寬（空氣中約 4%～75%），現場禁明火、禁產生火花的工具、禁止穿易產生靜電的衣物。
  • 直流電沒有零交越點，拉弧不會自行熄滅。斷開直流迴路一定要照程序、用對開關。
  • 電堆怕缺氣也怕反極：啟停要照程序做吹掃，不能直接斷電走人。
